VectorFunction final

Represents a vector function which may be constructed from values which can be converted to objects of type RealFunction.

In general one may construct any VectorFunction by specifying its values in a uniform initialization manner. For example, to construct a VectorFunction with constant entries (1, 2, 3) . auto v = VectorFunction{1, 2, 3}; Alternatively, we may construct instances of VectorFunction from any type which is convertible to specializations of RealFunction.

auto s = RealFunction(3.1416);
auto v = VectorFunction{Dx(s), 42, s};
