template<class LinearSystem, class TrialFunction _2, class TestFunction _3>
Problem& Rodin::Variational::Problem<LinearSystem, TrialFunction, TestFunction><LinearSystem, _2, _3>::assemble() override

Assembles the whole linear system.

Assembles the linear system and establishes the initial guess.

After assembly, the linear system's solution vector holds the trial function data as the initial guess: on entry to a linear solver the solution vector is the guess, on exit it is the solution. Trial functions are zero-initialized, so the guess is zero unless set.

template<class LinearSystem, class TrialFunction _2, class TestFunction _3>
void Rodin::Variational::Problem<LinearSystem, TrialFunction, TestFunction><LinearSystem, _2, _3>::solve(SolverBaseType& solver) override

Assembles if stale, solves the linear system, and writes the result to the trial function solution.

Assigning a new problem body with operator=() marks the current assembly stale. If that happens, or if assemble() has not been called yet, this function calls assemble() before invoking the linear solver.
