Jacobian final

Jacobian of a P0g vector ShapeFunction (identically zero).

Defined in Rodin/Variational/P0g/Jacobian.h

template <
  class ShapeFunctionDerived,
  class Scalar,
  class Mesh,
  ShapeFunctionSpaceType Space>
class Jacobian<
  ShapeFunction< ShapeFunctionDerived, P0g< Math::SpatialVector< Scalar >, Mesh >, Space >> final;

This is the Jacobian of the basis functions of P0g; since those are constant, their Jacobians are zero.
