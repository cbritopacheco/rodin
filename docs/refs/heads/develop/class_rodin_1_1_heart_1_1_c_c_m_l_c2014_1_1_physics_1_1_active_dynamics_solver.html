template<class Input>
Rodin::Heart::CCMLC2014::Physics::ActiveDynamicsSolver class

Solves the local active dynamics and computes condensed active stress/tangent for the global balance.

Template parameters
Input Model input parameter type.

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions

At each global Newton iteration, the local fiber deformation and internal variables are resolved iteratively. The condensed active stress and its displacement derivative are then returned for assembly into the global residual and Jacobian.
