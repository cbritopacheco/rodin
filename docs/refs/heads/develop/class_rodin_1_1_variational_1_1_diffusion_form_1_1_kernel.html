Rodin::Variational::DiffusionForm::Kernel class

Local kernel of the diffusion form.

Contents

  • Reference
    • Public types
    • Constructors, destructors, conversion operators
    • Public functions

Evaluates the reference gradients once per polytope geometry and quadrature order and reuses them across polytopes, pulling them back through the metric at each polytope. The kernel owns a copy of the coefficient, so that each thread assembling with its own copy of the kernel also evaluates its own copy of the coefficient.
