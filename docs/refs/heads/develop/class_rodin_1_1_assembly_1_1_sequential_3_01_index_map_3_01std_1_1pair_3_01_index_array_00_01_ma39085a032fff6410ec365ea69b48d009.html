Rodin::Assembly::Sequential<IndexMap<std::pair<IndexArray, Math::Vector<Scalar>>>, Variational::DirichletBC<Variational::TrialFunction<Sol1, FES1>, Variational::ShapeFunctionBase<Derived2, FES2, Sp>>> class final

Sequential assembler for the identification Dirichlet BC u = A(v).

Contents

  • Reference

Iterates the default exterior boundary when no attributes are specified. When attributes are specified, every tagged codimension-one face is eligible, including interior interface faces. On each selected face, the slave DOFs (from 's FES) and the master DOFs (from 's FES) are obtained exactly via FiniteElementSpaceBase::getDOFs(face) — no geometric matching, no tolerance.

For each slave DOF a pair (masters, coefficients) is emitted. Each coefficient is computed as : the master basis is evaluated through and then sampled by the slave finite element's DOF functional.
