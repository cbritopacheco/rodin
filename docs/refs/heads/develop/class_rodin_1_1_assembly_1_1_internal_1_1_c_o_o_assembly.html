COOAssembly

Device system assembled into a coordinate list for PETSc.

Defined in Rodin/PETSc/Kokkos/Assembly/COOAssembly.h

template <
  class Backend>
class COOAssembly;
Template parameters
Backend Kokkos backend of the mesh context.

The integrators write their entries into a coordinate list in device memory. The fixed degrees of freedom are eliminated and the identified ones are expanded on their masters on the device, and the values summed per distinct coordinate are handed to MatSetValuesCOO. The system may be distributed over MPI processes.

using Range = ::Kokkos::RangePolicy<ExecutionSpace, ::Kokkos::IndexType<Index>>

Range of the kernels, indexed by Index.

The default index of a Kokkos 5 range is the index_type of the execution space, a 32 bit int on the GPUs, and a bound past it aborts. One process can hold more than 2^31 entries.

template<class Backend> template<class Indices, class Order>
static void sortPattern(const ExecutionSpace& execution, size_t columns, const std::vector<COOSegment>& segments, const std::vector<size_t>& offsets, const Indices& rows, const Indices& cols, const Order& order, size_t blockSize = SortBlockSize)

Sorts the coordinates into the given indices.

Parameters
execution Execution space instance of the kernel.
columns Column count of the system.
segments Segments of the coordinates.
offsets Position of the first entry of every segment.
rows Row coordinates.
cols Column coordinates.
order Receives the indices of the sorted coordinates.
blockSize Target maximum number of coordinates sorted at once.

The rows are split in ranges of at most SortBlockSize coordinates, by halving, and the ranges are sorted one after the other in row order. Contribution rank breaks coordinate ties, so every bucket size and backend produces the same permutation.

Distributes the system over MPI processes.
