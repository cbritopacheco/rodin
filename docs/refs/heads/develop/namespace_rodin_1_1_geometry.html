Rodin::Geometry module

Meshes, geometric transformations, and mapped evaluation.

Mesh<Context::MPI> and getConnectivity().compute(d1, d2) describe mesh entities and their incidence relations. Polytope, Geometry::Point, and PolytopeTransformation connect reference elements to physical geometry for integration, field evaluation, mesh extraction, and deformation.

Key classes include:

  • Mesh<Context::MPI> — The primary mesh class supporting triangular, quadrilateral, tetrahedral, and hexahedral meshes
  • Polytope — Geometric entities (vertices, edges, faces, cells) with type enumeration
  • getConnectivity().compute(d1, d2) — Incidence relations between polytopes of different dimensions
  • Geometry::Point — Evaluation point for grid functions, bundling reference coordinates, physical coordinates, Jacobian data, and the owning polytope

Enum documentation

enum class Rodin::Geometry::Region

Defined in Rodin/Geometry/Region.h

Enumeration of standard mesh regions.

This enumeration defines commonly used subregions of a mesh that can be referenced in variational formulations and boundary conditions.

Enumerators
Cells

Interior cells (elements) of the mesh.
Faces

All faces (d-1 dimensional polytopes) in the mesh.
Boundary

Boundary faces (faces incident to only one cell).
Interface

Interior faces (faces incident to two cells).
