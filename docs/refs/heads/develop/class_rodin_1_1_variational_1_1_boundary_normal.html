Rodin::Variational::BoundaryNormal class final
#include <Rodin/Variational/BoundaryNormal.h>

Outward unit normal vector on domain boundaries.

Contents

  • Reference
    • Base classes
    • Public types
    • Constructors, destructors, conversion operators
    • Public functions

BoundaryNormal represents the outward-pointing unit normal vector field on the boundary of a mesh. It is computed from the mesh geometry and element transformations.
