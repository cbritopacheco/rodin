Architecture

Each formula family and constructor-key type has a shared owning pool. Integer and enum arguments are copied into a tuple; published formula arguments are borrowed through their permanent addresses. Tuple comparison uses total pointer ordering for those references. No caller-owned formula can enter a persistent cache through this interface.

A bounded thread-local lookup borrows published formulas. Shared lookups and insertion hold the pool mutex. Construction occurs outside the mutex so generators may request other formulas. Concurrent misses may construct duplicate candidates, but publish only one. Pools retain their entries until process termination, including throughout static destruction. All published concrete rules own their immutable samples; reading them requires no lock.

Constructor arguments must determine all generated samples. Generators must own their samples or borrow storage with process lifetime, and must not retain caller-owned constructor arguments. They must not depend on unsynchronized mutable state or cyclic factory requests.

Function documentation

static const QuadratureFormula& get(size_t order, Geometry::Polytope::Type geometry)

Selects a persistent quadrature formula for a reference geometry.

Parameters
order Required polynomial degree of exactness.
geometry Reference polytope geometry.
Returns Immutable formula retained until process termination.

Uses positive interior published tables where available and Gaussian product rules beyond their supported degrees. Tensor factors are persistent formulas from the same thread-safe factory.

template<class Formula, class... Args>
static const QuadratureFormula& get(Args && ... args)

Constructs or retrieves a persistent formula of a concrete family.

Template parameters
Formula Concrete generator implementing QuadratureFormulaBase.
Args Integer, enum, or persistent-formula constructor arguments.
Parameters
args Arguments forwarded to the generator on a cache miss.
Returns Immutable formula retained until process termination.

Argument value types select distinct pools; family factories normalize counts and orders to size_t. Generator exceptions publish no entry. Returned references are independent of constructor-argument lifetimes.
