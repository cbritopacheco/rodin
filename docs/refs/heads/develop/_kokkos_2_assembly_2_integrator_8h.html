Rodin/Kokkos/Assembly/Integrator.h file

Host-side dispatch of polymorphic Rodin integrators to Kokkos.

Contents

  • Reference
    • Namespaces
    • Functions

Assembly receives type-erased core integrator lists. Runtime casts unwrap scaling and negation and select the backend interface once while preparing each assembly input. They do not execute in element or quadrature kernels. Unsupported integrators raise instead of silently selecting host evaluation.
