SpaceFillingCurveOrdering

Bounding-box quantization and sorting for spatial ordering policies.

Defined in Rodin/Geometry/SpaceFillingCurveOrdering.h

template <
  class Derived>
class SpaceFillingCurveOrdering;
Template parameters
Derived Concrete ordering policy returned by configuration setters.

Contents

  • Reference
    • Public functions
    • Protected functions

The stages are coordinate validation, bounding-box normalization, integer quantization, policy transformation and stable sorting of interleaved keys. No mesh incidence is computed or modified.

Function documentation

Derived& setBitsPerCoordinate(Optional<size_t> bits)

Sets the quantization precision.

Parameters
bits in Bits per coordinate, or std::nullopt for automatic precision.
Returns Reference to the concrete ordering policy.

Explicit precision must be positive and at most 52. Application to a mesh additionally requires at most 63 bits across all coordinates. Automatic precision is the smaller of 52 and 63 divided by the space dimension, rounded down.

Optional<size_t> getBitsPerCoordinate() const

Gets the requested precision.

Returns Explicit bit depth, or std::nullopt for automatic precision.

Computes a spatial vertex ordering.

Template parameters
Transform Callable transforming quantized coordinates before interleaving.
Parameters
mesh in Local mesh with finite vertex coordinates.
transform in Concrete ordering's coordinate transformation.
Returns Permutation with newToOld[newIndex] equal to the old vertex index.

Each coordinate is normalized independently in the mesh bounding box. Constant coordinate directions quantize to zero. Equal keys retain the original vertex order, including coincident vertices.
