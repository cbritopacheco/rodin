Properties a correct quadrature rule must satisfy, none of which depend on the closed-form moment oracle.

Contents

  • Reference
    • Functions

The exactness sweep compares a rule against moments I derived by hand. That is a strong test but it shares one assumption with the rule: what the reference element is. A rule and an oracle built on the same wrong element agree with each other perfectly. The checks here are chosen to be blind to that: they compare the rule against itself under transformations that must leave the integral invariant, so they hold whatever the element is.

Function documentation

TEST(QuadraturePropertyTest, IntegralIsAdditiveUnderSubdivision)

Subdivision consistency.

Integrating over a simplex must equal the sum over any set of pieces that tiles it. This uses no moment formula whatsoever: the rule is compared only against itself, applied to sub-elements through affine maps. A rule that integrated the wrong domain, or that was exact only by agreement with a mistaken oracle, fails here.

TEST(QuadraturePropertyTest, IntegralScalesWithTheAffineDeterminant)

Affine covariance.

A rule exact on the reference element is exact on any affine image of it, with the integral scaling by the determinant. This is the property assembly actually relies on, and it is what makes a reference rule usable at all.

TEST(QuadraturePropertyTest, ExactOnRandomPolynomialsNotOnlyMonomials)

Exactness on random polynomials, not only on monomials.

The sweep tests one monomial at a time, so an error that cancels between monomials of the same degree would pass it. A random combination does not cancel.

TEST(QuadraturePropertyTest, TheTwoFamiliesAgree)

The two families must agree.

XiaoGimbutas and WitherdenVincent are independent published families and produce different point counts. Two rules of the same strength must nevertheless integrate every polynomial of that degree identically.

TEST(QuadraturePropertyTest, AccuracyImprovesWithDegreeOnASmoothIntegrand)

Accuracy on a non-polynomial integrand improves with degree.

Exactness on polynomials is a statement about a finite-dimensional space; the reason to want it is that it makes smooth integrands converge. A table whose higher-degree entries were not actually better would satisfy every other test here.
