Architecture

Trial/test identities and cumulative DOF offsets are passed directly to the problem assembly selected by Default. That single assembler owns block insertion and completion. No auxiliary sequential tuple assembler is constructed: its availability must not restrict the scalar or storage types supported by the selected problem assembler. The formulation and assembled system are owned; trial/test functions are borrowed. Assignment replaces these values and bindings while retaining the destination identity. Cumulative offsets are established at construction and refreshed at assembly: and for the ordered trial/test spaces. Unused per-block forms are not materialized.
