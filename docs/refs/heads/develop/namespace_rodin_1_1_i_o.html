Rodin::IO module

Reading and writing meshes, fields, and associated data.

Contents

MeshLoader and MeshPrinter import and export meshes; GridFunctionLoader and GridFunctionPrinter transfer discrete fields. Format-specific backends support MFEM, MEDIT, and HDF5 data, while XDMF writes meshes, multiple fields, and time series for visualization.

Supported mesh and field formats include:

  • MFEM (IO::FileFormat::MFEM) — Native MFEM mesh and grid function format
  • MEDIT (IO::FileFormat::MEDIT) — MEDIT format used by MMG and INRIA tools
  • HDF5 (IO::FileFormat::HDF5) — High-performance binary format

Additionally, the XDMF class provides XDMF 3.0 output for scientific visualization in ParaView, supporting time series and multiple fields.

XDMF Architecture

The XDMF writer uses a two-level design:

  • XDMF — Top-level writer that manages the .xdmf XML file and .h5 HDF5 data. Provides write(), flush(), close(), setPadding().
  • XDMF::Grid — A lightweight handle returned by xdmf.grid() (default) or xdmf.grid("name") (named). Provides setMesh(), add(), hasMesh(), reset() — all returning Grid& for method chaining.
IO::XDMF xdmf("output");
xdmf.grid().setMesh(mesh).add("u", u.getSolution());
xdmf.write();

For MPI-distributed I/O, pass the communicator:

IO::XDMF xdmf("distributed_output", MPI_COMM_WORLD);

Enum documentation

enum class Rodin::IO::FileFormat

Enumeration of supported file formats for mesh and grid function I/O.

This enum identifies the different file formats that can be used for reading and writing meshes and grid functions in Rodin.

Enumerators
MFEM

MFEM mesh format - native format for MFEM library.
MEDIT

MEDIT mesh format - used by MMG remeshing software.
HDF5

HDF5 hierarchical binary format for raw mesh/function storage.
