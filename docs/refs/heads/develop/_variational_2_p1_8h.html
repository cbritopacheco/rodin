Vertex-based continuous finite element spaces and their form operators.

Contents

    • Reference and physical shape functions
    • Usage
    • Operators

The scalar family has one degree of freedom at each mesh vertex. Shared vertex coefficients identify compatible traces across neighboring cells. Vector and matrix ranges repeat the scalar construction componentwise.

Reference and physical shape functions

On a simplex the reference space is affine. . Product cells use their vertex-based product spaces that are bilinear on quadrilaterals, trilinear on hexahedra and triangle-by-segment on wedges. The pyramid uses its rational reference construction. The physical functions are .

The physical gradient is constant on affine simplices. Non-affine maps and the other cell families generally produce varying gradients. Approximation estimates require the corresponding mesh regularity, mapping and solution assumptions.

Usage

Given a mesh with boundary connectivity and a source coefficient f, the following code constructs the scalar Poisson form.

P1 space(mesh);
TrialFunction u(space);
TestFunction v(space);
Problem poisson(u, v);
poisson = Integral(Grad(u), Grad(v)) - Integral(f, v)
        + DirichletBC(u, Zero());

Include Rodin/Variational.h for the complete form vocabulary and Rodin/Solver.h for solvers. The runnable Poisson tutorial includes the mesh, solve and output.

Operators

This aggregate provides P1 derivatives, gradients, divergence, Jacobians, shape-function operators, potential forms, quadrature dispatch and linear elasticity integrators. Range and geometry restrictions are documented on the corresponding specializations.
