Abstract base class for a Dirichlet boundary condition.

Encodes the essential constraint

applied DOF-functional-wise: for each slave DOF on the assembled object encodes a row of the form

which Problem / ProblemBody enforce strongly when assembling the global linear system.

The right-hand side of has two representations, exposed through a discriminated union via getDOFs:

  • Value-prescribing : a scalar — known at assembly time.
  • Identification : a sparse linear combination with coefficients — coupling unknown DOFs of to unknown DOFs of .

Concrete subclasses fill exactly one alternative of DOFs.

template<class Scalar>
using Rodin::Variational::DirichletBCBase<Scalar>::DOFs = std::variant<ValueDOFs, IdentifiedDOFs>

Variant DOF type covering both Dirichlet semantics.

The active alternative depends on which subclass produced it: a value-prescribing BC writes the ValueDOFs alternative, an identification BC writes the IdentifiedDOFs alternative.

template<class Scalar>
Optional<Identifiable::UUID> Rodin::Variational::DirichletBCBase<Scalar>::getValueUUID() const virtual

Returns the UUID of 's leaf trial function for an identification BC, or nullopt for a value-prescribing BC.

Consumer assemblies use this to locate 's trial block and apply the correct global offset when assembling identified-DOF constraints.

template<class Scalar>
const IdentificationValues& Rodin::Variational::DirichletBCBase<Scalar>::getIdentificationValues() const virtual

Returns optional defects for affine identification BCs.

Value-prescribing BCs and homogeneous identification BCs return an empty map. Affine identification BCs override this to provide the known additive defect value for each slave row.
