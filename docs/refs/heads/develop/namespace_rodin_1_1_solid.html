A total-Lagrangian hyperelastic model uses a reference domain , displacement and deformation gradient . The stored energy determines the first Piola–Kirchhoff stress and tangent action.

The solid mechanics guide derives the weak equations and explains the reference/current configurations.

Constitutive models involving and inverse deformation gradients require an admissible deformation, including . ConstitutivePoint combines the kinematics, optional spatial location and tagged auxiliary inputs such as reference fibers and activation. Integrator input callbacks populate those values at quadrature points.

Prepare and evaluate a law

HyperElasticLaw defines the common constitutive interface. Bind a constitutive point through setConstitutivePoint(point), then read getStrainEnergyDensity(), getFirstPiolaKirchhoffStress(P) and getMaterialTangent(dP,dF). Binding captures the inputs needed by the law. Each assembly worker uses its own prepared law; concurrent rebinding of the same object requires synchronization.

The checked constitutive-response example varies and compares a centered energy derivative with over 71 stretches. Its largest scaled discrepancy was with finite-difference increment .

    for (size_t sample = 0; sample < 3; ++sample)
    {
      const Real value = stretch + (Real(sample) - 1) * increment;
      Math::SpatialMatrix<Real> gradient(3, 3);
      gradient.setZero();
      gradient(0, 0) = value - 1;
      Solid::KinematicState state(3);
      state.setDisplacementGradient(gradient);
      Solid::ConstitutivePoint point(state);
      law.setConstitutivePoint(point);
      energy[sample] = law.getStrainEnergyDensity();
      if (!std::isfinite(energy[sample]))
        return EXIT_FAILURE;
      if (sample == 1)
      {
        Math::SpatialMatrix<Real> firstPiola;
        law.getFirstPiolaKirchhoffStress(firstPiola);
        stress = firstPiola(0, 0);
        if (!std::isfinite(stress))
          return EXIT_FAILURE;
      }
    }

Other laws include SaintVenantKirchhoff, MooneyRivlin and HolzapfelOgden. Their class pages specify energy, dimensions, parameters and auxiliary inputs. Choose units consistently for the geometry, material parameters and loads.

Assemble internal virtual work

InternalVirtualWork binds a material law to the current displacement. Its residual and tangent represent

The façade supplies Residual(v), Tangent(du,v) and their combined form.

auto internal = Solid::InternalVirtualWork(law, displacement);
Problem newton(du, v);
newton = internal(du, v) - Integral(bodyForce, v)
       + DirichletBC(du, Zero()).on(fixedBoundary);

Here displacement is the current state, du is its trial increment and v is the matching test function. Problem assembly negates the physical residual when placing linear forms on the right-hand side, giving . Keep the state and forms valid throughout Newton updates. Nonpolynomial laws and curved geometry require quadrature assessed against the intended accuracy.
