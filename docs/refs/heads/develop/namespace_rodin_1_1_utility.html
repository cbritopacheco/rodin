Rodin::Utility module

Type utilities and generic programming helpers.

Contents

  • Reference
    • Classes
    • Typedefs
    • Functions
    • Variables

ParameterPack and Zip support compile-time type and parameter manipulation. Overloaded combines callable visitors, and OptionalReference represents optional non-owning access. These helpers support generic expressions, type dispatch, and reusable library extensions.

For example, Overloaded builds a visitor from lambdas:

std::variant<int, Real> value = 2;
const Real result = std::visit(Utility::Overloaded{
  [](int x) { return Real(x); },
  [](Real x) { return x; }
}, value);
