Computes the Jacobian matrix of an H1<K> vector-valued grid function:

where is the scalar basis count and the field component count. Reference gradients have entries; physical gradients retain all ambient entries.

The inverse geometric Jacobian is evaluated at the current sample. Curved mappings need not produce polynomial physical derivatives.

Applications

  • Strain tensor in elasticity:
  • Velocity gradient in fluid mechanics
  • Deformation gradient in nonlinear mechanics
