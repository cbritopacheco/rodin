Rodin::Heart::CCMLC2014::Physics::MidpointKinematics class

Evaluates midpoint kinematics for the 0D reduced cavity model.

Template parameters
Input Model input parameter type.

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions

Given the candidate unknowns at and the previous values at , computes:

  • Midpoint displacement
  • Midpoint pressures
  • Midpoint radial velocity
  • Reduced right Cauchy-Green scalar
  • Green-Lagrange strain
  • Strain derivative
