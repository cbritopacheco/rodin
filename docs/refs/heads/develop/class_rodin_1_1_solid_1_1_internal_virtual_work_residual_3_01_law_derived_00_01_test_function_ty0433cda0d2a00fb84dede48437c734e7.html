#include <Rodin/Solid/Integrators/InternalVirtualWorkResidual.h>
template<class LawDerived, class TestFunctionType, class DisplacementType, class PressureType>
Rodin::Solid::InternalVirtualWorkResidual<LawDerived, TestFunctionType, DisplacementType, PressureType> class final

Momentum residual of the mixed u-p formulation. Bound to the displacement test function .

Contents

  • Reference
    • Public types
    • Constructors, destructors, conversion operators
    • Public functions

The constitutive law must supply only the isochoric part of the stress; the volumetric response is carried by the pressure field.
