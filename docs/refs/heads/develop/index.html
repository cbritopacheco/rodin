Rodin

Modern C++20 finite element method and shape optimization framework.

What is Rodin?

Rodin is a lightweight and modular C++20 finite element framework designed for solving partial differential equations (PDEs) and performing shape and topology optimization.

It is named after the French sculptor Auguste Rodin, considered the founder of modern sculpture.

Active development

The library is in active development and primarily maintained by Carlos Brito-Pacheco, who is actively looking for co-maintainers.

Architecture

The core modules form the central stack. Models build on these interfaces to the left; third-party integrations and dependencies sit to the right. Shared services support the library across these layers.

Download and build

See the Installation guide for detailed instructions, dependency lists, and platform-specific notes.

Bash installation

git clone --recursive https://github.com/cbritopacheco/rodin
cd rodin
git lfs install
git lfs pull  # required for resources
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j4

Git LFS

If you only need the library and headers, configure with -DRODIN_INSTALL_RESOURCES=OFF and skip hydrating the Git LFS resources.

Philosophy behind Rodin

The architecture follows mosra's "batteries included, but screws not glued in" philosophy from the Magnum Engine project. For Rodin it means meshes, finite element spaces, forms, assembly, and solvers work together, while their interfaces remain accessible for extensions. A custom solver, constitutive law, or integrator can reuse the surrounding components.

The form language keeps the mathematics visible in C++. For real-valued scalar fields , , and on ,

Spaces, integrals, and boundary conditions are composed explicitly; assembly and the chosen solver realize the discrete problem. Module boundaries follow these responsibilities, allowing new models to reuse existing geometry, evaluation, and algebra.
