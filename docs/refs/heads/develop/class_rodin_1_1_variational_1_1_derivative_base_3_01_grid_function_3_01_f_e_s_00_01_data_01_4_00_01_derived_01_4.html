template<class FES, class Data, class Derived _3>
ScalarType Rodin::Variational::DerivativeBase<GridFunction<FES, Data>, Derived><FES, Data, _3>::getValue(const Geometry::Point& p) const

Evaluates the partial derivative at a Point.

Resolves mesh ownership and dispatches to the derived class's interpolate. Falls back to inclusion / submesh restriction when the polytope's mesh is not the FES mesh.

template<class FES, class Data, class Derived _3>
ScalarType Rodin::Variational::DerivativeBase<GridFunction<FES, Data>, Derived><FES, Data, _3>::getValue(const IntegrationPoint& ip) const

Evaluates the partial derivative at an IntegrationPoint.

If the polytope is owned by the FES mesh, dispatches to interpolate(out, ip). Otherwise falls back to inclusion / submesh restriction.
