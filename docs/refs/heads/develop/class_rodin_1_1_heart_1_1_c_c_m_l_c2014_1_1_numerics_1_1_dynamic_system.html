Rodin::Heart::CCMLC2014::Numerics::DynamicSystem class

Assembles the coupled residual and Jacobian for the 0D CCMLC2014 model.

Template parameters
PassiveLaw Passive stress operator type (functor).
Input Model input parameter type.

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions

This class composes the individual physics evaluators and provides three main operations:

  • buildEvalData: populate the intermediate evaluation data structure from the candidate unknowns and time-history states.
  • evaluateResidual: assemble the nonlinear residual vector.
  • evaluateJacobian: assemble the consistent tangent (Jacobian) matrix.

void Rodin::Heart::CCMLC2014::Numerics::DynamicSystem<PassiveLaw, Input>::evaluateResidual(const EvalData& evalData, DenseVector& residualVector) const

Evaluate the coupled 0D residual vector.

Template parameters
DenseVector Dense vector type.
EvalData Evaluation data structure type.
Parameters
evalData in Fully populated evaluation data.
residualVector out Residual vector (resized to NumberOfVariables).

The residual encodes:

  • Row 0 (RadialDisplacement): wall momentum balance (inertia + stress divergence - pressure loading).
  • Row 1 (VentricularPressure): cavity mass balance (compliance + valve flux + volume rate).
  • Row 2 (ArterialPressure): proximal Windkessel balance (compliance + resistive flow - outflow).
  • Row 3 (DistalPressure): distal Windkessel balance.
