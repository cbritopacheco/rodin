HyperElasticLaw

CRTP base class for hyperelastic constitutive laws.

Defined in Rodin/Solid/Constitutive/HyperElasticLaw.h

  class Derived>

A hyperelastic material is characterized by a stored energy density function from which all stress measures derive.

Each derived class implements:

  • Binding: Captures inputs and prepares private law-specific data.
  • First Piola-Kirchhoff stress:
  • Material tangent: Directional derivative

Binding is non-const. Evaluation methods are const and use the captured inputs until the next binding, without retaining references to the point. Copies own independent prepared state; each assembly worker uses its own law. Concurrent binding of the same law requires external synchronization.
