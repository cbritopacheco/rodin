The Xiao–Gimbutas [14] and Witherden–Vincent [13] rules are published positive-interior formulas. Rodin vendors their coefficients with the corresponding attribution licenses; no numerical search occurs at runtime.

API and caching

using namespace Rodin;

const auto& cached = QF::PolytopeQuadratureFormula::get(
  8, Geometry::Polytope::Type::Tetrahedron);

QF::PolytopeQuadratureFormula owned(
  8, Geometry::Polytope::Type::Tetrahedron);

PolytopeQuadratureFormula::get returns a process-wide canonical formula. Repeated per-thread requests are served by a small thread-local cache. PolytopeQuadratureFormula::build and the constructor return owned formulas. XiaoGimbutas, WitherdenVincent, GaussLegendre, GaussLobatto, and GrundmannMoller can also be selected explicitly. Grundmann–Moller is not a default because its weights are signed above degree one.

Curved elements

The rule order applies on the reference polytope. On a physical cell, the mapped integrand also contains the determinant of the geometric Jacobian. Non-affine transformations can therefore require an order above the degree suggested by the finite-element fields alone. A quadrature point must remain inside the reference polytope because a curved transformation is not required to extend beyond it.
