Executes targeted mixed problem assembly.

Parameters
axb Output linear system.
input Mixed problem input.
target Side of the system to assemble.

The full system is assembled into temporary storage. Only the requested side is transferred to the output system; the other side is preserved. This uses the same boundary-condition elimination as full assembly.
