Owning backend compressed row matrix.

Sparse matrix in compressed row storage, resident in the memory space of a Kokkos backend.

Architecture

The owner holds a native KokkosSparse::CrsMatrix and a writable handle to its row offsets for reassembly. Both handles refer to the same allocation. getView() exposes the native matrix without copying it. The device assembly of a Problem builds it without copying the matrix to the host, so that a solver running on the device reads it in place. The columns of a row are sorted and unique. Copies are deep, as for Rodin::Math::SparseMatrix; moves keep the storage.
