The geometric reference

The largest disk touches the square at two points. The disks have disjoint interiors. Their union has signed distance

negative inside and positive outside. This analytic field supplies both the implicit geometry and a reference for the normalized output.

    RealFunction exact([](const Point& point) {
      return std::min(
        {std::hypot(point.x() - Real(0.75), point.y() - Real(0.25)) - Real(0.05),

The material split explicitly assigns inside cells attribute 3, outside cells attribute 2 and interface edges attribute 5. The field used to drive remeshing is scoped to that operation. The following solve uses a new space on the returned mesh.

Solve the auxiliary problem

With the mesh's inside region and its marked interface, the scalar potential satisfies

The exterior boundary portions have the homogeneous Neumann condition of the weak formulation. The force is negative inside and positive outside. The fitted interface provides the essential condition that anchors each region. The corresponding constrained stiffness matrix is symmetric positive definite.

The program constructs this problem explicitly so that CG convergence and the assembled residual can be checked before normalization. The same attributed forcing is used by SignedPoisson.

    P1 space(mesh);
    TrialFunction u(space);
    TestFunction v(space);
    Problem potential(u, v);
    potential = Integral(Grad(u), Grad(v)) + Integral(2 * v).over(Inside) - Integral(v) +
      DirichletBC(u, Zero()).on(Interface);
    Solver::CG solver(potential);
    constexpr Real LinearTolerance = Real(1e-10);
    solver.setTolerance(LinearTolerance).solve();
    if (!solver.success())
      return EXIT_FAILURE;
    const auto& system = potential.getLinearSystem();
    const Real relativeResidual =
      (system.getOperator() * system.getSolution() - system.getVector()).norm() /
      std::max(Real(1), system.getVector().norm());
    constexpr Real ResidualTolerance = Real(1e-9);
    if (!std::isfinite(relativeResidual) || relativeResidual > ResidualTolerance)
      return EXIT_FAILURE;
    const auto& poisson = u.getSolution();
    auto normalized = Distance::SpaldingTucker()(poisson);
    GridFunction reference(space);
    reference = exact;

SpaldingTucker evaluates

and interpolates it into the input space. A positive denominator preserves the sign of the potential pointwise. The expression requires a defined gradient and becomes undefined when the potential and its gradient vanish together. The executable checks the resulting nodal values for finiteness.

Build and inspect the output

Build the SpaldingTucker target and run it in a scratch directory. It generates its input mesh and writes DistanceNormalization.xdmf with its HDF5 companions. The arrays are potential, normalized and reference. DistanceNormalization.csv records mesh counts, inside area, nodal errors, interface values and the relative algebraic residual.

The program requires CG success, a residual below , finite nodal fields, nonempty inside/outside regions and interface values within of zero. The recorded distance errors describe this approximation and geometry.
