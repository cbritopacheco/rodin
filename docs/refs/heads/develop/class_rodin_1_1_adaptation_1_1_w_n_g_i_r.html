Rodin::Adaptation::WNGIR class

Backend-independent WNGIR mesh-fitting solver.

Fits the interface skeleton of a mesh to the zero level set of by repeatedly solving a regularized first-derivative metric problem and line-searching the resulting displacement on the true geometry.

Constructed from backend-matched trial and test functions, the solver uses the ordinary Rodin form-language deduction path for the step Rodin::Variational::Problem, the metric Rodin::Variational::BilinearForm, and Rodin::Solver::CG. Every global quantity is a backend-matched GridFunction; only element-local geometry uses Math::SpatialVector / Math::SpatialMatrix. WNGIR contains no backend-specific code.
