Physical-gradient preparation

The scalar basis gradients are mapped at the current physical sample by . If both operands borrow the same reference-table object, these images share one scratch buffer. Distinct tables retain separate buffers even when their sizes agree. Identity is checked during the current borrow; no table pointer is retained and physical gradients are never reused across binds. Each cell and quadrature point recomputes its physical gradients. Mapping expressions and local-entry summation order remain unchanged.

Component-block contraction

Let and denote physical trial and test scalar bases, and let count scalar components of the value range. The component basis has local index . The underlying scalar bases are real-valued in both real and complex H1 spaces. Their mapped gradients define the scalar block

Here is the mapped reference sample and is its reference quadrature weight. Only the first component block is accumulated over quadrature points. Its entries are copied to the remaining component-diagonal blocks after the sweep; cross-component entries retain their initialized zeros. This preserves each entry's quadrature summation order without allocating a separate scalar matrix. Matrix-valued ranges use their flattened scalar components. Component-coupling weighted forms have a separate contract.

Zero component ranges produce a matrix before scalar tabulation or contraction, including for unequal polynomial degrees. On a point, the physical derivative is zero and no scalar gradient contraction is performed, independently of the ambient dimension.
