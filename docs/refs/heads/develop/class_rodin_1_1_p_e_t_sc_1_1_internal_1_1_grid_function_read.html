Reads a PETSc vector or its ghosted local form.

Defined in Rodin/PETSc/Kokkos/Variational/GridFunctionAdapter.h

  class Execution>

Array access starts lazily after cache validation. Borrowed arrays remain valid until destruction. The caller completes all reads before destruction.
