Manufactured-solution tests for the Poisson problem using the PETSc solver backend (sequential, Context::Local).

Contents

  • Reference

The PDE is:

The weak form is assembled by Variational::Problem<PETSc::Math::LinearSystem, U, V> and solved with PETSc::Solver::CG (conjugate gradient).

Each test verifies numerical correctness by comparing the FE solution against the known manufactured solution in the norm.
