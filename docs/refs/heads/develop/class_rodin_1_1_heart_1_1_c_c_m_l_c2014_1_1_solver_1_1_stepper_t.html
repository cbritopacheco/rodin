#include <Rodin/Heart/CCMLC2014/Solver/Stepper.h>
template<class PassiveEnergyLaw, class PassiveLaw>
Rodin::Heart::CCMLC2014::Solver::StepperT class

Time-stepper for the coupled 0D CCMLC2014 ventricular model.

Template parameters
PassiveEnergyLaw Passive-energy law used by the constitutive response.
PassiveLaw Passive stress operator using passive-energy derivatives.

Contents

  • Reference
    • Public types
    • Constructors, destructors, conversion operators
    • Public functions

Manages the Newton iteration for one time step, delegating residual and Jacobian assembly to the Numerics::DynamicSystem class, and updating the model state on convergence.
