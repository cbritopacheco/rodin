Imposes the inhomogeneous (or homogeneous, if ) Dirichlet condition

algebraically: for each slave DOF of on ,

where is the slave finite element's DOF functional — point evaluation for Lagrange, an integral / moment pairing for non-nodal elements. The assembler streams these scalars into the DirichletBCBase::ValueDOFs alternative of the variant returned by getDOFs.

In the global linear system the slave row is replaced by an identity row with right-hand side and the slave column is moved to the RHS:

.on(attr...) selects tagged codimension-one facets for ; without .on(...), all exterior boundary faces are used.
