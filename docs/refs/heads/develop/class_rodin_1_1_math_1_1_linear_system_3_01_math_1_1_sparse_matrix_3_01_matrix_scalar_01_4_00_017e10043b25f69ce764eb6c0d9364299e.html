Architecture

Let be the constrained indices, their diagonal indicator, , and the prescribed vector extended by zero outside . The operation replaces by

Thus free equations retain their original coefficients and receive the lifting ; constrained equations become . Neither symmetry of values nor transpose storage is required. In particular, no conjugation enters the lifting for complex systems. The solution vector is preserved for warm starts.

Implementation

All constrained columns contribute to the load before any coefficient is cleared. Their diagonal positions are recorded after each column's traversal. Absent diagonals are inserted together by one backwards merge of the compressed arrays, preserving sorted row indices and all existing stored entries, including explicit zeros.

A byte per row identifies constraints. Adjacent constrained columns are cleared as contiguous storage ranges. Between these ranges, blocks of sixteen row indices form a bit mask: empty masks require no coefficient stores, while nonempty masks visit only their set bits. Sixteen is a kernel granularity, not a numerical threshold. The tail uses bit masking for Real and conditional zero assignment for other scalars; multiplication by zero would not clear nonfinite values. Finally the diagonals and prescribed load entries are restored.

For a single contiguous constraint interval, a bounded sample may select exact row-range pruning. This heuristic requires at least eight entries per column on average and at least half of sixteen storage- quantile samples to reject the interval. These measured policy choices select a kernel only: each skipped column is independently certified by its actual row bounds. Partial columns use binary searches. Fragmented constraints always use the block kernel.

With rows, stored entries and constraints, the block path takes work and scratch. The optional pruning path additionally performs at most two binary searches per overlapping free column. Matrix storage grows only by the number of absent constrained diagonals. No transpose index, full matrix copy, persistent cache, or worker pool is constructed.
