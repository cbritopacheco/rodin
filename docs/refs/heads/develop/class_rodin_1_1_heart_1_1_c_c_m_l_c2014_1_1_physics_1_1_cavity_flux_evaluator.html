Rodin::Heart::CCMLC2014::Physics::CavityFluxEvaluator class

Evaluates cavity inflow/outflow fluxes through the valve branches.

Template parameters
Input Model input parameter type.

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions

Determines the valve state (mitral open, both closed, aortic open) based on the relative pressures and computes the corresponding volume flux and its derivatives with respect to ventricular and arterial pressures.

The three valve regimes are:

  • Mitral open: — filling phase.
  • Both closed: — isovolumetric phase.
  • Aortic open: — ejection phase.
