QualityCovering final

Cached closed-form reference coverings with equal positive base weights.

Defined in Rodin/Adaptation/SWIFT/QualityCovering.h

class QualityCovering final;

The integer indices of the subdivision lattice are shifted and contracted. Except on tetrahedra, coordinates are . Tetrahedra use , with for and otherwise. Point counts are unchanged. These structured coverings have known reference radii; unrestricted optimality is not claimed. Vertices are not supplemental witnesses.

Architecture

Generation visits the reference geometry's integer index set once and applies its closed-form contraction. Immutable formulas are cached by geometry and subdivision. Equal base weights sum to reference volume. The quadrature interface supplies mapped-point caching, not polynomial exactness or a continuous quality certificate.
