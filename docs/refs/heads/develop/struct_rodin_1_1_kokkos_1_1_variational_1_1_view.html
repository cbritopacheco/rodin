Template parameters
Node Form language expression type.

A view is built on the host from the expression and copied by value into kernels. It holds no host pointer and no virtual function. Function views provide getValue(const Rodin::Kokkos::View<::Rodin::Geometry::Point>&), while shape function views provide getBasis(const IntegrationPointView&, Index, Index), which returns the value of component r of the basis function of the local scalar degree of freedom a. A scalar view has the single component 0.

The primary template is left undefined so that an expression without a device lowering is rejected at compile time.
