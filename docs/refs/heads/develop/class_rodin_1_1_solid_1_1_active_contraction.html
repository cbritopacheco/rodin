ActiveContraction final

Adds active fiber stress to a passive law.

Defined in Rodin/Solid/Constitutive/ActiveContraction.h

template <
  class PassiveLaw,
  class ActiveLaw = ActiveFiberLaw>
class ActiveContraction final;
Template parameters
PassiveLaw Passive constitutive law with non-const binding and const evaluation.
ActiveLaw Three-field active law providing residual and partial tangent blocks.

Contents

  • Reference
    • Inherits from
    • Constructors, destructors, conversion operators
    • Public functions

The passive law can be any Rodin hyperelastic law. The active contribution is aligned with Tags::FiberDirection and uses Tags::ActiveExtension; if dynamic tags are present (TimeStep, PreviousActiveExtension, PreviousActiveGamma, PreviousActiveBeta, ElectricalActivation), the active extension, gamma and beta must also be supplied as independent discontinuous fields. Const accessors expose their residual and tangent blocks for a coupled global Newton solve; no local solve or condensation occurs.
