Enum documentation

enum class Keyword

Keywords used in MEDIT mesh and solution file formats.

These keywords identify different sections in MEDIT files (.mesh and .sol). The MEDIT format is a text-based format used by the MMG remeshing software.

See also

MEDIT Format Specification
