Dense coefficient vector with backend storage and value semantics.

Architecture

The owner retains one Kokkos allocation. Copies are deep; getView() borrows its allocation for kernels. Arithmetic, reductions and segment copies run in the execution space. Scalar host access transfers only the requested entry through a proxy; upload() and download() copy independent values across the host/backend boundary and complete before returning. Resizing invalidates borrowed views. The Kokkos runtime must outlive owners.
