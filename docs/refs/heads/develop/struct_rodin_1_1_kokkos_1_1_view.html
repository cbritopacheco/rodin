Template parameters
T Represented Rodin type.

Specializations live in the corresponding Kokkos module. Geometry views borrow resident arrays and expire on owner replacement; constitutive views copy material parameters. Construction does not synchronize or transfer an owning object. Unsupported types have no default implementation. This object interface is distinct from Kokkos::View array storage.
