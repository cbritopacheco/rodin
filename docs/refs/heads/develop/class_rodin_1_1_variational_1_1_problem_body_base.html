ProblemBodyBase

Base class representing the body of a variational problem.

Defined in Rodin/Variational/ProblemBody.h

template <
  class Scalar>
class ProblemBodyBase;
Template parameters
Scalar Scalar type for problem coefficients

Contents

ProblemBodyBase manages all integrators and boundary conditions for a variational problem, providing a unified interface for problem assembly. It serves as the container for all mathematical components of the discrete system.
