General concepts » Matrix storage and finite-element component ordering

Matrix storage, tensor storage and finite-element coefficient numbering describe different representations. Storage order determines the position of an entry in an object's memory. Component numbering determines the association between a coefficient and a basis function. Mathematical indexing remains independent of both representations.

Matrix storage

Matrix and FixedSizeMatrix use Eigen's default column-major storage. For a dense matrix with rows, entry has offset , with zero-based indices. Rows vary fastest within each column. SparseMatrix explicitly uses column-major compressed sparse storage; its entries are not a contiguous dense array.

SpatialMatrix also uses column-major storage, in a fixed three-by-three backing matrix. Its runtime dimensions select an active upper-left block. Consequently, its backing-storage offset is , including when the active row count is smaller than three. The active entries of a rectangular spatial matrix must not be treated as a packed array with leading dimension equal to its runtime row count. Access through operator()(i,j) preserves the mathematical indexing.

Explicit row-major Eigen buffers occur in local integration kernels. These are internal storage choices and do not change the default storage of public matrix types or the numbering of finite-element coefficients.

Consequences for assembly

A change of component numbering permutes coefficient vectors and the rows and columns of assembled operators. Such a change requires coordinated updates to basis evaluation, component access, DOF maps, persistence and interoperability. Changing memory order alone does not redefine components.

For uncoupled matrix mass and stiffness forms in the componentwise spaces, interleaved numbering gives . With scalar local basis functions, full dense traversal examines entries although only component pairs can contribute. Switching between row-major and column-major component numbering does not remove this structural work. Assembly must preserve the form's component coupling to avoid traversing absent pairs; coupled constitutive forms require their actual coupling pattern.
