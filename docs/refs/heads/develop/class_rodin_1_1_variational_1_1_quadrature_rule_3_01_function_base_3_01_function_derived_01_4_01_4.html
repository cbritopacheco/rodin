Quadrature rule for integrating general functions on mesh polytopes.

This specialization evaluates scalar-valued function integrals on a single polytope using a quadrature formula and the corresponding mapped geometric quadrature points owned by the rule.

A generic polytope quadrature of order 1 is selected for the current polytope geometry, including when binding a different reference cell. The corresponding mapped quadrature is owned until the next bind.
