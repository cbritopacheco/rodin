Architecture

Identification rows specify . A master can itself be constrained on another rank. Every rank therefore needs the complete constraint dependency graph before expanding a local matrix entry. Only prescribed values and identification rows are exchanged; matrix entries and unconstrained rows are not communicated here.

Implementation

Two collective gathers publish fixed rows and affine identification rows. Replicated boundary rows must agree, independently of master ordering. The native ConstraintMap then resolves transitive dependencies, propagates affine offsets and rejects cycles. Every rank receives the same graph, including ranks with no locally constrained DOFs. Assemblers invoke this collective only for identification conditions; ordinary value-prescribing boundaries retain their existing communication.
