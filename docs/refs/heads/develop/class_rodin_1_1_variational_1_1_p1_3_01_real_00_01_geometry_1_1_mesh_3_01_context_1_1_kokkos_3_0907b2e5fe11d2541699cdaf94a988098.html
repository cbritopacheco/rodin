P1 final

Real valued P1 Lagrange space on a resident Kokkos mesh.

The space numbers one degree of freedom per mesh vertex, as the host P1 space does, so a local mesh and the resident mesh built from it share their global numbering. Local degrees of freedom follow the vertex order of each polytope.

The host members answer the form language queries made while building and copying forms. Device evaluation of the basis goes through Rodin::Kokkos::View<::Rodin::Geometry::Point>::evaluate(), which is the P1 Lagrange basis of each reference geometry.
