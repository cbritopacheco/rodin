Rodin::Geometry::SubMesh<Context::MPI> class final

SubMesh representing a distributed subregion of a parent MPI mesh.

Contents

    • Base classes

A SubMesh<Context::MPI> is an MPI mesh that represents a subset of polytopes from a parent Mesh<Context::MPI>, maintaining bidirectional index mappings between submesh-local shard indices and parent-local shard indices.

Each rank independently builds its portion of the submesh by including entities from its parent shard. The submesh keeps a collective logical dimension, so ranks that select no local top-dimensional entities still agree on the dimension of the distributed submesh.

The submesh initially inherits ownership metadata from the parent shard. Finalization reconciles selected shared entities because the parent owner of an entity need not participate in a strict submesh such as a boundary skin.

Usage

Creating a distributed boundary submesh:

SubMesh<Context::MPI>::Builder builder;
builder.initialize(mpiMesh);

// Include all owned boundary faces on this rank
for (auto it = mpiMesh.getBoundary(); it; ++it)
  builder.include(mpiMesh.getDimension() - 1, it->getIndex());

SubMesh<Context::MPI> boundary = builder.finalize();

size_t Rodin::Geometry::SubMesh<Context::MPI>::getDimension() const override

Gets the collective topological dimension of the distributed submesh.

Returns Collective topological dimension.

This is the maximum included entity dimension across all ranks, not the dimension of the rank-local shard. Empty ranks therefore report the same logical submesh dimension as ranks that own selected entities.
