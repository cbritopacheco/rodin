template<class GradDerived, class Displacement, class LocatorType>
Rodin::Adaptation::SWIFT::FittingTensor class final

Matrix coefficient of the SWIFT surface fitting metric. Hessian of half the squared residual, with omitted and fixed gradient-scale normalization.
