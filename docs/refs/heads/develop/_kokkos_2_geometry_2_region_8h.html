template<class AttributeView>
bool isIntegrated(const ::Rodin::Kokkos::View<::Rodin::Geometry::MeshBase>& view, ::Rodin::Geometry::Region region, const ::Rodin::Kokkos::View<::Rodin::Geometry::Polytope>& polytope, const AttributeView& attributes)

Tests whether a polytope is integrated over a region.

Parameters
view Device mesh.
region Integration region.
polytope Device polytope of the dimension of the region.
attributes Selected attributes; empty selects every polytope of the region.
Returns Whether the polytope is integrated.

Boundary faces are incident to one cell and interface faces to more than one, as on the host. These regions need the face to cell incidence. Polytopes of a distributed mesh are integrated by their owner only.
