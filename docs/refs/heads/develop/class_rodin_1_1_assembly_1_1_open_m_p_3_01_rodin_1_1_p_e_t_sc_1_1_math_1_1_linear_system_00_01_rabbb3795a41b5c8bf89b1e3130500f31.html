OpenMP-parallel assembly of a single-variable PETSc problem.

Template parameters
U Trial function type.
V Test function type.

Assembles a Rodin::Variational::Problem backed by PETSc objects using OpenMP threads, populating both the system matrix and right-hand side vector.
