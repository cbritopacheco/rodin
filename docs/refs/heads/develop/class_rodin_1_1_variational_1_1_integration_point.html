IntegrationPoint

Evaluation point used by variational operators.

Defined in Rodin/Variational/IntegrationPoint.h

class IntegrationPoint;

Contents

  • Reference association
  • Reference
    • Constructors, destructors, conversion operators
    • Public functions

An IntegrationPoint borrows a geometric point and optionally records the formula/index of its originating integration loop. This sampling metadata does not certify that the point still has that formula's reference coordinates: mapping a face sample into a cell changes the chart.

Reference association

Construction from PolytopeQuadrature and a logical index establishes reference association through owned samples, without coordinate comparisons. getReferenceQuadratureFormula returns that formula only when construction established this reference association. Direct point/formula/index construction records provenance only. Reference tabulation and coordinate-sensitive reuse must use the reference accessor; an absent association selects the supplied point's reference coordinates. Coefficient snapshots may still use the originating sampling metadata.

Note

The quadrature formula pointer is non-owning. The referenced quadrature object must outlive all IntegrationPoint uses that dereference this pointer.

Parameters
quadrature Owner of the mapped point and its reference association.

No reference to the quadrature container is retained. The point and formula must outlive this binding, including after a container move. The formula is immutable and retained until process termination. Geometry changes require normal mapped-point reconstruction and rebinding.
