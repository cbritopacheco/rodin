#include <Rodin/Math/SpatialTensor.h>
template<class ScalarType, size_t Rank>
Rodin::Math::SpatialTensor class

A rank-R spatial tensor with stack storage and runtime extents.

Contents

Each axis has at most RODIN_MAXIMAL_SPACE_DIMENSION entries. Active entries are stored lexicographically, with the last index varying fastest. Rank three represents ; contracting its last axis with a vector gives . Inner products conjugate the second operand, as in Rodin::Math. Tensor actions on vectors and matrices use ordinary linear contractions.

Architecture

Runtime extents determine the active contiguous prefix of a fixed-size array. Indexing checks every axis; arithmetic checks matching extents. No heap allocation or implicit flattening into a spatial vector occurs.
