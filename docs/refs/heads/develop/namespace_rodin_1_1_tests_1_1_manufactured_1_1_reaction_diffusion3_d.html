Rodin::Tests::Manufactured::ReactionDiffusion3D namespace

Contents

  • Reference
    • Typedefs
    • Functions

3D manufactured tests for the reaction–diffusion equation:

Strong form: -Δu + α u = f in Ω u = g on ∂Ω

Weak form: ∫_Ω ∇ u·∇ v dx + α ∫_Ω u v dx = ∫_Ω f v dx

Geometry note: UniformGrid({M,M,M}) creates coordinates {0,…,M−1}. We scale by 1/(M−1) so the physical domain is [0,1]^3, matching the manufactured expressions.
