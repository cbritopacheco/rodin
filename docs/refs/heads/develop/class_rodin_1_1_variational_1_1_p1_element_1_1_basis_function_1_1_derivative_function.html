Computes the pure reference-coordinate derivative . Nonpyramid bases are linear in each coordinate separately, so pure derivatives of order two or greater vanish. The four pyramid base functions contain , giving for . At the pyramid apex, higher derivatives retain the zero convention; this value is not a continuous extension of the interior derivatives.
