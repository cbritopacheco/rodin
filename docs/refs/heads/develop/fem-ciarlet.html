General concepts » Ciarlet's definition of a finite element

Separate the reference cell, approximation space, and degrees of freedom.

A finite element is a local construction. It specifies which functions can be represented on one cell and which measurements determine those functions. A finite element space combines these local constructions over a mesh, with the required continuity between neighboring cells.

The finite element triple

A finite element is a triple with the following components:

ObjectRole
Reference cell on which the local construction is defined
Finite-dimensional space of functions on that cell
Linear functionals determining a function in

The functionals are the degrees of freedom. Depending on the element family, they measure point values, moments, normal components, or tangential components. Together with the reference cell and approximation space, they specify the finite element.

  P1Element<Real> element(Polytope::Type::Triangle);
  std::ofstream basis("ReferenceP1.csv");
  basis.precision(17);
  basis << "i,j,r,s,phi0,phi1,phi2\n";
  for (size_t i = 0; i <= subdivisions; ++i)
  {
    for (size_t j = 0; j <= subdivisions - i; ++j)
    {
      const Math::SpatialPoint point{Real(i) / subdivisions, Real(j) / subdivisions};
      basis << i << ',' << j << ',' << point.x() << ',' << point.y();
      for (size_t k = 0; k < element.getCount(); ++k)
        basis << ',' << element.getBasis(k)(point);
      basis << '\n';
    }
  }

The reference cell is used here, so the sampling coordinates are reference coordinates. A value evaluated on a physical mesh cell must also use that cell's geometric mapping.

Polynomial degree is a property of the reference approximation space. Under a non-affine geometry map, the physical basis is the composition of a reference polynomial with the inverse map. Field degree and geometry degree are selected independently.

Assemble a global space

Local DOFs on shared mesh entities are identified when the chosen continuity requires it. Continuous nodal spaces share vertex values and, at higher degree, the appropriate edge and face data. Discontinuous spaces retain independent cell data.

Locate the objects in Rodin

Polytope::Type identifies a reference geometry. Element classes such as P1Element provide local basis evaluations and DOF functionals. Space objects distribute DOFs over a mesh, while GridFunction represents one discrete field in that space.

  constexpr size_t nodes = 8;
  Mesh mesh = Mesh().UniformGrid(Polytope::Type::Triangle, {nodes, nodes});
  mesh.scale(1.0 / (nodes - 1));
  mesh.getConnectivity().compute(1, 2);
  mesh.getConnectivity().compute(2, 1);
  P0 cellSpace(mesh);
  P0g constantSpace(mesh);
  P1 linearSpace(mesh);
  H1 quadraticSpace(std::integral_constant<size_t, 2>{}, mesh);
  P1 vectorSpace(mesh, 2);
  P1<Complex> complexSpace(mesh);

This setup defines several spaces on the same mesh for comparison. The finite element spaces guide checks their global counts, assigns a known function, and evaluates the interpolated fields. See also the polytope guide and numerical contracts.
