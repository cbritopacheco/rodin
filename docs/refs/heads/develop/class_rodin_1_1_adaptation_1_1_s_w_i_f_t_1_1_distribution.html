Distribution final

Sparse core of the frozen centered current-strain bilinear form.

Defined in Rodin/Adaptation/SWIFT/Distribution.h

template <
  class TrialFunction,
  class TestFunction,
  class Displacement>
class Distribution final;

Binds cached geometry and basis Jacobians, evaluates j and F^-1 once per quadrature point, then tabulates sym(grad v F^-1) before contracting pairs. Computes the local weighted deviatoric and divergence products. Subtracting the global mean-strain couplings gives the centered form; no independent element means are subtracted. Assembly clones isolate bind state.

Global mean-strain subtraction represented by . Native linear forms integrate the symmetric strain in an orthonormal tensor basis. The volume and moments use the sparse core's quadrature, preserving the variance identity for the centered form. Current volume is integrated directly as the same reference weights times geometric distortion and deformation determinant. Interpolated position fields cannot define this volume when displacement degree is below map degree.
