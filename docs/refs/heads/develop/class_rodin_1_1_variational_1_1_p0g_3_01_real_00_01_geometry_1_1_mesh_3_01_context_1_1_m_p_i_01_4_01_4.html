Distributed scalar P0g finite element space for MPI meshes.

Contents

  • Reference
    • Base classes
    • Public types
    • Constructors, destructors, conversion operators

Wraps a local shard scalar P0g space and provides the distributed interface. All ranks see the same single global DOF (index 0).

Function documentation

template<>
Rodin::Variational::P0g<Real, Geometry::Mesh<Context::MPI>>::P0g(const MeshType& mesh) explicit

Constructs the distributed scalar P0g space on the given mesh.

Parameters
mesh in Distributed mesh on which the space is defined.

The underlying shard P0g space is created from the local mesh shard. No MPI communication is required.

template<>
void Rodin::Variational::P0g<Real, Geometry::Mesh<Context::MPI>>::getOwnershipRange(Index& begin, Index& end) const

Returns the ownership range .

Parameters
begin out First global DOF owned by this rank.
end out One past the last global DOF owned by this rank.

Rank 0 owns the single global DOF: begin = 0, end = 1. All other ranks own nothing: begin = end = 1.

template<>
const IndexArray& Rodin::Variational::P0g<Real, Geometry::Mesh<Context::MPI>>::getDOFs(size_t d, Index i) const override

Returns the global DOF array for local polytope .

For scalar P0g every polytope maps to the single global DOF 0.

template<>
Index Rodin::Variational::P0g<Real, Geometry::Mesh<Context::MPI>>::getGlobalIndex(Index) const

Returns the global DOF index for local shard DOF localIdx.

Returns Global distributed DOF index (always 0).

For scalar P0g there is only 1 global DOF (index 0), so this always returns 0 regardless of localIdx.

template<>
