Judgement

The following judgement specifies that the expression is a well formed type of QuadratureRule.

Implements the linearized convection term for Navier-Stokes using multi-point quadrature appropriate for the polynomial degree.

The scalar nodal bases are real-valued over both real and complex fields. Hence with Rodin's test-second conjugated dot product. The coefficient remains linear; conjugating would change the represented expression. Physical gradients have the ambient dimension, including rectangular inverse Jacobians on embedded cells. Point cells and empty component ranges return the zero operator before evaluating the coefficient.

Working storage

Each sample stores once per trial scalar basis, rather than retaining a full gradient and contracting it again for each test basis. Matrix traversal and per-entry accumulation remain unchanged. The thread-local scalar buffer only grows. A nested same-type integrator may grow or overwrite it during coefficient evaluation, but the outer invocation then computes every active entry before use. Physical gradients are local bounded values constructed after that callback, so no ambient dimension metadata can be inherited from the nested operation. Scalar reference tables are also acquired after the callback.
