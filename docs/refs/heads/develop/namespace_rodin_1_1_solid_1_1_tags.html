Rodin::Solid::Tags namespace

Standard tag types for auxiliary constitutive data.

Contents

  • Reference
    • Classes

Each tag defines a nested Type alias indicating the value type stored and retrieved via ConstitutivePoint::set / get.

cp.set<Tags::FiberDirection>(fiberVec);
const auto& fiber = cp.get<Tags::FiberDirection>();
