Rad

Represents an angle in radians.

Defined in Rodin/Math/Rad.h

class Rad;

Contents

  • Example Usage
  • Reference
    • Inherits from
    • Public types

This class provides a type-safe wrapper for angles measured in radians, inheriting all the unit arithmetic operations from the Unit base class.

Example Usage

Rad angle1(Math::Constants::pi());  // π radians (180 degrees)
Rad angle2(Math::Constants::pi() / 2);  // π/2 radians (90 degrees)
Rad sum = angle1 + angle2;  // 3π/2 radians
