Reference moments and rule invariants shared by the quadrature tests.

Contents

  • Reference
    • Namespaces
    • Classes

The exactness check compares a rule against closed-form moments of the reference polytope, so it needs no reference implementation and cannot inherit an error from one. Every reference element below is the unit element used by Rodin::QF; the moment formulae are derived for exactly those domains.
