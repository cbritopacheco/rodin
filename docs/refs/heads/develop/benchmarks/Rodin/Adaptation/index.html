Adaptation

Published configurations

Mesh adaptation and deformation operations.

SWIFT::Adapt and SWIFT::Problem fit mesh interfaces to level sets while controlling element distortion. DeformationMap and CellDeformation describe mapped geometry for evaluating deformed cells and fields. These components support moving-interface calculations and body-fitted mesh updates.
