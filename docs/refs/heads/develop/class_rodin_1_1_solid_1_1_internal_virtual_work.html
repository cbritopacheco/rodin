Rodin::Solid::InternalVirtualWork class

Façade for the internal virtual work nonlinear form.

Template parameters
Law The hyperelastic constitutive law type
State The displacement grid-function type

Contents

  • Reference

Owns the constitutive law, a reference to the current displacement, and optional configuration (quadrature order, auxiliary input). Exposes .Residual(v), .Tangent(u, v), and operator()(u, v) (which combines both into a ProblemBody for direct use in a Problem assignment).

Note

The combined operator()(u, v) intentionally returns Tangent(u, v) + Residual(v). Problem assembly places linear forms on the right-hand side with a minus sign, so this is the correct convention for NewtonSolver.

template<class Law, class State>
InternalVirtualWork& Rodin::Solid::InternalVirtualWork<Law, State>::setInput(InputFunction input)

Sets the auxiliary input for both residual and tangent.

The input is propagated to every quadrature point in both Residual() and Tangent() integrators, ensuring they see the same fiber directions, activation parameters, etc.

template<class Law, class State>
InternalVirtualWork& Rodin::Solid::InternalVirtualWork<Law, State>::setOutput(OutputFunctionType output)

Sets the output invoked at each quadrature point by commit().

The output is the dual of setInput(): it reads the law's cache after evaluation, and is the extraction site for committed internal variables, recovered stresses or diagnostics. It is invoked only by commit(), never during assembly, so a caller controls exactly when derived quantities are taken.

template<class Law, class State>
void Rodin::Solid::InternalVirtualWork<Law, State>::commit() const

Evaluates the law at every quadrature point and invokes the output. Performs no assembly.

Sweeps the cells of the displacement's mesh, reproducing the constitutive evaluation of Residual() and Tangent() at the current displacement – the same kinematics, the same ConstitutivePoint, the same Input – and hands each resulting cache to the output. Callers use this to commit internal variables once a nonlinear solve has converged, without recomputing the kinematics themselves.

The quadrature rule is the one set by setQuadratureOrder(), or the displacement's element order. This agrees with Residual() and Tangent() as long as the trial and test spaces do not exceed the displacement's order; otherwise pin the order with setQuadratureOrder() so that every pass addresses the same quadrature points.

Does nothing if no output has been set.
