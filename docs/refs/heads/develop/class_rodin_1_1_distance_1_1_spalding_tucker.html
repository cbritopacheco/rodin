Pointwise properties and discrete output

A positive denominator preserves the input sign and zero set before interpolation. The expression is undefined where both the field and its gradient vanish. Finite element interpolation and one-sided gradient evaluation affect the discrete result. The input scale and geometry determine the accuracy of the distance approximation; an analytic reference or refinement study supplies the relevant numerical check.
