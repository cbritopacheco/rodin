template<size_t K, class Scalar>
Rodin::Variational::H1<K, Scalar, Geometry::Mesh<Context::MPI>> class

Distributed H1 finite element space for MPI meshes (scalar range).

Template parameters
K Polynomial degree (≥ 1).
Scalar Scalar type (Real or Complex).

Contents

  • Reference

    • Constructors, destructors, conversion operators
    • Public functions

Wraps a local shard H1 space and augments it with distributed global indexing. DOFs are generated at every mesh entity dimension:

  • d = 0 (vertices): 1 DOF per vertex
  • d = 1 (edges, K≥2): K−1 interior DOFs per edge
  • d = 2 (faces, K≥3): (K−1)(K−2)/2 interior DOFs per triangle, (K−1)² per quadrilateral
  • d = 3 (cells, K≥4): tetrahedron/wedge/hexahedron interior DOFs

Owned degrees of freedom receive contiguous global indices per rank, and ghost/shared DOFs are synchronized from the owning rank.
