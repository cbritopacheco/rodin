Base

Base class for all objects in Rodin's FormLanguage system.

Defined in Rodin/FormLanguage/Base.h

class Base;

Contents

  • Key Features
  • Reference
    • Inherits from
    • Derived classes
    • Constructors, destructors, conversion operators
    • Public functions

This class serves as the foundational base for all form language objects, providing essential services such as unique identification, object lifetime management, and polymorphic copying capabilities. All form language expressions, functions, and operators derive from this base class.

Warning

The FormLanguage::Base class is not thread safe. Only one thread should access the methods of a FormLanguage object at a time.

Key Features

  • Unique Identification: Each instance receives a unique UUID for tracking
  • Polymorphic Operations: Support for copying and cloning operations
