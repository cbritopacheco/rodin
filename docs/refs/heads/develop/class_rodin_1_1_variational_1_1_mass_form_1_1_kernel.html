Kernel

Local kernel of the mass form.

Defined in Rodin/Variational/MassForm.h

class Kernel;

Contents

  • Architecture
  • Reference
    • Public types
    • Constructors, destructors, conversion operators
    • Public functions

Evaluates the reference bases once per polytope geometry and quadrature order and reuses them across polytopes; only the quadrature weights, the distortion of the map and the coefficient change from one polytope to the next. The kernel owns a copy of the coefficient, so that each thread assembling with its own copy of the kernel also evaluates its own copy of the coefficient.

Architecture

Reference preparation owns one basis-pair matrix per quadrature sample. Trial values are evaluated once into point-local scratch before the test-basis loop. Thus trial evaluations suffice instead of , without changing the dot products or the retained reference-matrix layout. The scratch is local to preparation, not a second persistent reference cache. Empty test ranges do not evaluate trial bases. Subsequent cells retain the original weighted accumulation.
