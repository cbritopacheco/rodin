template<size_t Dimension, class T>
class Point
Point with compile-time fixed coordinate storage. Arithmetic applies componentwise; subtracting two points yields a spatial displacement. The template dimension is a nonnegative compile-time coordinate count.
template<size_t Dimension, class T>
class LineSegment
Segment between distinct endpoints. The closed segment corresponds to ; parameter evaluation also accepts extrapolation. Storage has exactly Dimension components. Intersection returns a point only when unique, including a shared endpoint of collinear segments; positive-length overlaps return no unique point.
template<size_t Dimension, class T>
class Line
Affine line in a compile-time Euclidean dimension. with nonzero direction . Projection uses the Euclidean inner product. Closest points use direct formulas through dimension three and a fixed-size QR solve in higher dimensions. Unit direction columns use a rank threshold of twice scalar machine epsilon (relative to the largest QR pivot in higher dimensions). Numerically parallel directions have rank below two and admit no unique line intersection. Intersections return only unique points; coincident lines return no point.
template<size_t Dimension, class T>
class Sphere
Sphere in a compile-time ambient dimension. In one dimension the sphere comprises two endpoints; in two it is a circle.
template<size_t Dimension, class T>
class Hyperplane
