template<>
void setLHS(const IndexArray& lhs)

Captures the first element-local DOF map.

Parameters
lhs First support, in its own local basis order.

Each input contains distinct indices, as in the native finite element spaces. Equal indices across inputs denote the same global basis. Absent side-local indices represent a zero extension on that side.

template<>
void setRHS(const IndexArray& rhs)

Completes the binding with the second support and constructs the union.

Parameters
rhs Second support in its local basis order.

The first support is captured by setLHS before querying the second. This permits finite element spaces to return reusable scratch arrays.
