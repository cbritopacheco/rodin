Rodin::Adaptation::SWIFT namespace

Robust interface fitting with a fitting–distribution metric.

Contents

  • Reference
    • Classes
    • Functions

Problem computes displacement using , quadratic affine quality hinges and Armijo globalization. Adapt owns a local P1 setup and applies valid results to affine simplicial meshes. MPI/PETSc execution is not implemented.

Real getDirectionalNewtonStep(Real action, Real curvature, Real fittingCurvature, Real directionNorm, Real maximumStep)

Quadratic-model minimizer with an optional physical-motion bound. Positive fitting curvature supplies the fallback when robust curvature is nonpositive. A zero maximumStep leaves the directional Newton scale unrestricted.

Parameters
action Positive fitting-force action on the predictor.
curvature Robust-energy directional curvature.
fittingCurvature Positive squared-fit curvature used as a fallback.
directionNorm Physical displacement norm of the predictor.
maximumStep Physical-motion bound; zero leaves scaling unrestricted.
Returns Directional scale, or zero when the model inputs are invalid.
