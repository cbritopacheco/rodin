Rodin::Variational::GridFunctionBase class

Base class for discrete finite element functions.

GridFunctionBase represents discrete functions defined on finite element spaces, where the function is represented as a linear combination of basis functions with scalar coefficients stored in a data vector.

Key Features

  • DOF Management: Automatic handling of degrees of freedom storage
  • Function Evaluation: Point-wise evaluation via finite element interpolation
  • I/O Support: Export to various visualization formats (MEDIT, MFEM)
  • Space Association: Strong association with underlying finite element space

Abstract base class for GridFunction objects.

This class contains the common routines for the behaviour of a GridFunction object. It provides a common interface for the manipulation of its data and weights, as well as projection utilities and convenience functions.

Projection semantics

Assigning an expression to a grid function computes the interpolant: the space's degree-of-freedom functionals are applied to the expression, . This is not the -orthogonal projection — the two coincide only when the expression already lies in the space. When the projection is required (e.g. for optimal-order transfer of rough data), solve the mass-matrix problem explicitly:

TrialFunction u(vh);
TestFunction  v(vh);
Problem l2(u, v);
l2 = Integral(u, v) - Integral(f, v);
Solver::CG(l2).solve();

Coefficients vs values

For nodal spaces of degree one (P1) the coefficient vector holds vertex values. For higher-order spaces (H1\<K\>, ) the underlying basis is not plain nodal Lagrange, and coefficients are not nodal values: always evaluate through getValue() (or the element basis) instead of reading the data vector positionally.

Thread safety

Concurrent reads (getValue() from multiple threads) on a fully constructed grid function are safe; any mutation (assignment, setData(), load()) requires exclusive access. See the thread safety guide.
