Rodin brings together contributions from its scientific community and established numerical software. The acknowledgments below identify people and laboratories, followed by the roles of runtime libraries, optional backends and development tools.

People

Scientific discussions and collaboration support the development of Rodin and its applications. This section acknowledges members of that community.

Oscar Ruz

Universidad de Santiago de Chile. Member of the Computational Heat and Fluid Flow Lab.

Laboratories

Research laboratories provide a setting for applications, numerical-method development and scientific exchange. The laboratory below is part of that research community.

Computational Heat and Fluid Flow Lab

CFD-LAB, Universidad de Santiago de Chile. Research in computational heat transfer, fluid flow, and fluid–structure interaction.

Third-party software

Libraries support algebra, geometry processing, data exchange and execution. Optional components are enabled according to the build configuration; their inclusion and license terms are documented by the linked projects. See Configuration for Rodin's build options.

Boost

Boost provides C++ utility libraries used by Rodin. Its libraries are distributed under the Boost Software License, also used by Rodin.

Eigen

Eigen supplies dense and sparse linear algebra, expression templates and local solver implementations. Its licensing page describes the Mozilla Public License 2.0 terms and applicable component details.

MMG

MMG provides two- and three-dimensional mesh adaptation, quality optimization and level-set reconstruction through Rodin's MMG interfaces. The project distributes its license terms. [4] describes three-dimensional mesh adaptation and level-set domain meshing.

HDF5

HDF5 provides structured binary storage for Rodin mesh and field output, including the data referenced by XDMF visualization files.

termcolor

termcolor supplies terminal colors for contextual diagnostics in the Alert module.

PETSc

PETSc supplies the optional distributed algebra, linear and nonlinear solvers, and preconditioners used by Rodin's PETSc backend.

SuiteSparse

SuiteSparse supplies the optional UMFPACK, CHOLMOD, SPQR, and ParU sparse solver backends. Individual components have their own license terms.

MUMPS

MUMPS provides the optional multifrontal sparse direct solver backend.

Scotch

Scotch provides graph partitioning for mesh decomposition through the Scotch module.

METIS

METIS provides graph partitioning and fill-reducing orderings used by supported sparse solver dependencies.

MPI implementations

MPICH and Open MPI provide implementations of the Message Passing Interface used in Rodin's distributed builds and continuous integration. Rodin uses MPI through its distributed mesh, finite element, and solver paths.

OpenMP

OpenMP provides the compiler and runtime interface used by optional shared-memory parallel code paths.

pybind11

pybind11 connects C++ interfaces to Python in Rodin's optional Python bindings.

Development and documentation tools

These tools build the test and benchmark evidence and render the documentation. They support development, validation and presentation.

GoogleTest

GoogleTest supplies the C++ testing framework used by Rodin's unit and regression tests.

Google Benchmark

Google Benchmark supplies the benchmark framework used to measure Rodin's numerical kernels and assembly operations.

Doxygen

Doxygen extracts API declarations and documentation from Rodin's C++ sources and documentation pages.

m.css

m.css renders the extracted documentation and supplies the site theme and documentation components.

Jinja

Jinja renders the HTML templates used by m.css and Rodin's documentation pages.

Pygments

Pygments provides syntax highlighting for code examples throughout the documentation.

LaTeX and dvisvgm

LaTeX typesets mathematical expressions, and dvisvgm converts the results into SVG images for the documentation.

Scientific references

The reference list collects the publications cited in the mathematical guides, numerical methods and API documentation. Citations on each page identify the source associated with the construction being discussed.
