template<class ProblemBody, class U1, class U2, class U3, class ... Us>
Rodin::Assembly::ProblemAssemblyInput<ProblemBody, U1, U2, U3, Us...> class

Input data for mixed problem assembly with several trial/test functions.

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions

Stores the split trial and test tuples, their block offsets, UUID-to-block maps, and the total trial/test sizes used to assemble a mixed linear system.
