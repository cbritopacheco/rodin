Jacobian& setPolytope(const Geometry::Polytope& polytope)

Starts a fresh cell binding for physical basis derivatives.

Parameters
polytope Entity whose geometry remains fixed during this binding.
Returns This expression with no point bound.

Affine simplex derivatives are prepared at the first point and reused throughout this binding. Curved or varying reference derivatives are prepared at each new quadrature sample. Rebinding the same entity discards the preceding physical results while retaining storage.

Jacobian& setIntegrationPoint(const IntegrationPoint& ip)

Sets the integration point the expression is evaluated at.

Parameters
ip Integration point at which the expression is evaluated.
Returns Reference to this object after the operation.

Pyramidal scalar basis derivatives are rational and sample-dependent. An affine geometric map therefore does not justify reusing a vector basis Jacobian at another reference sample. Tensor-product and pyramidal reference derivatives retain sample-indexed reuse.

For the scalar basis and component , . The scalar physical gradient is contracted once per vertex, in the original summation order, then copied into each component row. Reference and physical scratch vectors have fixed-capacity stack storage; no per-bind heap scratch is needed.
