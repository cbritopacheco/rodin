#include <Rodin/Solid/Integrators/InternalVirtualWorkResidual.h>
template<class LawDerived, class TestFunctionType, class DisplacementType>
Rodin::Solid::InternalVirtualWorkResidual class

Linear form integrator for the internal virtual work residual in hyperelastic problems.

Template parameters
LawDerived The hyperelastic constitutive law type
TestFunctionType The test function type (backend-generic)
DisplacementType The current displacement grid-function type

Computes the element-level contribution:

The test function and current displacement state are kept as their concrete Rodin types. The displacement gradient and test-basis gradients are evaluated through Variational::Jacobian(...), so PETSc or other storage backends work as long as they provide the usual Rodin traits and Jacobian specialization. An optional Input can inject auxiliary data (fiber directions, activation, etc.) into the ConstitutivePoint at each quadrature point.

Typically constructed via InternalVirtualWork::Residual(v) rather than directly.
