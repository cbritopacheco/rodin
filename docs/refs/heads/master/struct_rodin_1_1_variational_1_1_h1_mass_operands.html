H1MassOperands

Certifies the plain-leaf operands of an H1 weighted mass expression.

Defined in Rodin/Variational/H1/QuadratureRule.h

template <
  class Expression>
struct H1MassOperands;

Contents

  • Specializations
  • Reference
    • Public static variables

Only a direct H1 trial leaf has the component support used by the mass rule. Nested products, traces and transformed shapes retain generic integration. This metadata neither rewrites nor owns an expression.

Specializations

In the table, denotes a coefficient expression and a direct H1 trial leaf. Eligibility retains operand order; it does not assert that a general coefficient commutes with the trial field.
