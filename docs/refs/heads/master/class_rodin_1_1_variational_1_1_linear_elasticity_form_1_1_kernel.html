Kernel

Local kernel of the linear elasticity form.

Defined in Rodin/Solid/Linear/LinearElasticityForm.h

class Kernel;

Evaluates the reference derivatives of every basis function once per polytope geometry and quadrature order and reuses them across polytopes; at each polytope they are pulled back through and combined into divergences and symmetric gradients. The kernel owns copies of the Lamé parameters, so that each thread assembling with its own copy of the kernel evaluates its own copies.

Trial-side weighting

At each quadrature point, trial divergences are multiplied by the first Lamé parameter and trial symmetric gradients by the shear modulus before visiting test functions. The resulting arguments of dot are reused without changing conjugation, quadrature order or the local entry accumulation sequence. No additional buffer or cross-point physical cache is introduced.

Spatial contraction

At spatial dimension , const Eigen views expose the known column extent while retaining dynamic rows. Other dimensions retain the original spatial-matrix expression. Policy selection occurs once per cell, before the integration implementation; both policies compute the same test-conjugating Frobenius product. Quadrature, material weighting, entry order and backend insertion are unchanged. No state, geometry comparison or collective operation is added.
