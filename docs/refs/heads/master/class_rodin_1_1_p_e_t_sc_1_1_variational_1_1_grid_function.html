GridFunction

Convenience wrapper that inherits all functionality from GridFunction<FES, ::Vec>.

This thin derived class lives in the Rodin::PETSc::Variational namespace and pulls in all base-class constructors, operators, and methods via using declarations. Its sole purpose is to enable cleaner user-facing syntax:

PETSc::Variational::GridFunction u(Vh);

instead of the fully-qualified specialization name.

ScalarType& operator[](Index global)

Provides mutable element access by global DOF index.

Parameters
global in Global DOF index.
Returns Mutable reference to the DOF coefficient .

Lazily acquires write access to the underlying PETSc array on first call. In Context::Local mode the index maps directly to the sequential array. In Context::MPI mode, owned indices are translated to while ghost indices are looked up in the GhostBimap.

Note

The caller must call flush() after all modifications to propagate ghost values back to their owners.

GridFunction& operator=(const GridFunction& other)

Copy assignment operator.

Parameters
other in Grid function to copy from.
Returns Reference to *this.

Deep-copies the DOF values of other into this grid function with VecCopy, followed by a forward ghost update in MPI mode.

The underlying Vec is reused: both operands are required to live on the same finite element space, so their layouts (ownership range and ghost mapping) are identical by construction and a fresh allocation would produce a vector indistinguishable from the one already held. Reuse also keeps the Vec handle stable, so a KSP, a LinearForm, or user code that cached getData() is not left holding a destroyed handle after an assignment. A new vector is created with VecDuplicate only when this instance holds none, which is the case for a moved-from object.

The destination completes its own pending writes. The source must have completed writes through its mutable owner before this const borrow.

Precondition

Both grid functions must reference the same finite element space.

GridFunction& operator=(GridFunction&& other) noexcept

Move assignment operator.

Parameters
other in Grid function to move from.
Returns Reference to *this.

Releases any existing PETSc handles via release(), then transfers ownership and outstanding array borrows from other. Moving requires exclusive access to both objects. Pending source writes remain pending until the new owner explicitly synchronizes them.

Precondition

Both grid functions must reference the same finite element space.
