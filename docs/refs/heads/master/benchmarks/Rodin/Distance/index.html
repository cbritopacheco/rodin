Distance

Published configurations

Distance-field computations.

Eikonal constructs distance fields through fast marching, while Poisson and SignedPoisson provide PDE-based alternatives. These models convert boundary or level-set information into distance approximations for shape optimization, interface processing, and mesh adaptation.
