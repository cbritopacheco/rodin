Quadrature formulae

Published configurations

Module for defining quadrature formulae over reference polytopes.

QuadratureFormula selects persistent reference integration rules by geometry and exactness. GaussLegendre, TensorProduct, and the simplex rule families supply points and weights for element integration and reference-basis tabulation.
