Rodin::Variational::P0<Range, Geometry::Mesh<Context::MPI>> class

Distributed P0 finite element space for MPI meshes.

Template parameters
Range Scalar or vector range descriptor used by P0.

Contents

  • Reference
    • Base classes

    • Constructors, destructors, conversion operators

This specialization wraps a local shard P0 space and augments it with distributed global indexing. Each cell of the distributed mesh carries exactly one degree of freedom. Owned cells receive contiguous global indices per rank, and ghost cells synchronize their global DOF index from the owning rank.

template<class Range>
Rodin::Variational::P0<Range, Geometry::Mesh<Context::MPI>><Range>::P0(const MeshType& mesh)

Constructs the distributed P0 space on the given mesh.

Parameters
mesh in Distributed mesh on which the space is defined.

Builds the local shard P0 space, then assigns contiguous global DOF indices to owned cells. Ghost cells obtain their global DOF index via a direct owner-push exchange:

  • Each rank iterates its owned cells and assigns a global DOF index where is the local owned- cell counter.
  • For each owned cell that also appears on neighboring ranks as a ghost (recorded in shard.getHalo(D)), the owner sends (globalCellID, globalDOF) to all holder ranks.
  • Each non-owner rank posts a matching irecv from its owner (recorded in shard.getOwner(D)) and installs the received global DOF index in the local-to-global map.
