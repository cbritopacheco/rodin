The tutorials explain a problem, its discretization, the code that realizes it, and the interpretation of the result. Source examples extend that workflow to other models and backends.

Start here

  1. Build a first program to create a mesh and a finite element space.
  2. Solve the Poisson equation to connect a weak form to assembly, a solver, and visualization.
  3. Continue with linear elasticity for a vector-valued field and boundary traction.

The General concepts guides supply the mathematical background. The Gallery collects visual results.

Before choosing a model

A variational problem combines a trial space, a test space, forms, and boundary conditions. The variational formulationsguide explains this construction; the solver guide explains how the resulting matrix properties determine solver choice.

Solid mechanics source examples

The Solid module provides hyperelastic constitutive laws and nonlinear integrators for large-deformation solid mechanics. The LinearElasticityIntegral covers the small-deformation (linearized) case, while the Solid module handles finite-strain problems with constitutive laws such as NeoHookean, Saint-Venant-Kirchhoff, and Mooney-Rivlin:

ProblemConstitutive LawExample
Linear cantilever beamSolving the elasticity equation
Hyperelastic cantilever (NeoHookean, transient)CantileverBeam.cpp
