Rodin::Variational::P0g<Math::SpatialVector<Real>, Geometry::Mesh<Context::MPI>> class final

Distributed vector P0g finite element space for MPI meshes.

Contents

  • Reference
    • Base classes
    • Public types
    • Constructors, destructors, conversion operators

Wraps a local shard vector P0g space and provides the distributed interface. All ranks see the same vdim global DOFs (indices 0 to vdim - 1).

void Rodin::Variational::P0g<Math::SpatialVector<Real>, Geometry::Mesh<Context::MPI>>::getOwnershipRange(Index& begin, Index& end) const

Returns the ownership range .

Parameters
begin out First global DOF owned by this rank.
end out One past the last global DOF owned by this rank.

Rank 0 owns all vdim global DOFs: begin = 0, end = vdim. All other ranks own nothing: begin = end = vdim.
