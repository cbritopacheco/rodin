Rodin::Adaptation module

Mesh adaptation and deformation operations.

Contents

  • Design
  • Key classes
  • Representative formula
  • Reference
    • Namespaces
    • Classes

SWIFT::Adapt and SWIFT::Problem fit mesh interfaces to level sets while controlling element distortion. DeformationMap and CellDeformation describe mapped geometry for evaluating deformed cells and fields. These components support moving-interface calculations and body-fitted mesh updates.

Design

The module follows a strict separation of concerns:

  • The level set owns the topology of the tracked domain ( inside, outside).
  • Classification converts into discrete cell attributes (see Geometry utilities such as the min s-t cut classifier).
  • Geometry fitting (SWIFT) moves and curves the mesh. It never decides topology.

The SWIFT step solves a metric-preconditioned (natural-gradient) problem built entirely in the variational form language: a surface force (the Welsch first variation, assembled on interface facets) balanced against fitting and centered distribution metrics. Affine quadratic hinges recover quality in the direction problem. Hard admissibility (element validity) is enforced by a nonlinear line search.

Key classes

  • Parameters — budgets, tolerances and weights
  • Report — per-solve diagnostics
  • Problem — local fitting without mesh mutation
  • Adapt — owned P1 setup and in-place displacement

Note

Interface-fitting constraints are formulated as smooth penalties; the module deliberately avoids hard geometric projections inside the solve, which break line-search continuity.
