Implementation

Entity binding constructs the union and its side-local numbering once. Point binding maps the face point into each cell and prepares two independent owned operand evaluations. Basis reads neither rebind an operand nor retain references to temporary points. Mapped cell coordinates do not inherit the face quadrature's reference association.
