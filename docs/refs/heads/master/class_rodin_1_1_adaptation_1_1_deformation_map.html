Architecture

A point binding locates the deformed point once and owns that result for all subsequent basis requests in the binding. Cell binding or invalidation releases it. Direct point evaluation always locates afresh. Neither the integration point nor a transformation-state token is retained. Geometry, displacement and locator data must remain unchanged during a binding. Copies retain the displacement and locator references but start unbound. Evaluation objects are local to a pass and must not be shared concurrently.
