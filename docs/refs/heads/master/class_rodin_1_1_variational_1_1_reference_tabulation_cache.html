Reuses scalar basis values and first derivatives at reference samples.

For the element's own basis and reference samples , the table stores and in quadrature-major order. No basis conversion, physical coordinates or mapped derivatives are stored.

Architecture

The bounded thread-local store is distinct for each element/scalar type. Persistent formula address and reference geometry identify an entry. Published formulas own immutable samples until process termination. Borrowed tables are valid only until a subsequent insertion evicts their slot; callers must consume them immediately. Arbitrary coefficient callbacks can insert tables even when their returned mathematical value is constant. Evaluate such callbacks before borrowing each table, and finish consuming it before invoking another callback. Eviction and cross-thread misses permit direct pointwise evaluation. Cells share reference data, not geometry-dependent matrices. Both public lookup operations use the same formula search. Construction is a separate stage: it retires an evicted key before changing storage and publishes the new key only after the element has filled the complete table. A request obtains its thread-local cache once and shares that reference between its lookup and construction stages. An element's basis must be determined solely by its type and reference geometry, as for P1 and fixed-degree H1; mutable basis parameters are not represented by this key. An element may supply a public bulk tabulation operation. It sizes and fills the caller-owned table; cache ownership, lookup, eviction and publication stay here. Elements without that operation use direct basis evaluation.
