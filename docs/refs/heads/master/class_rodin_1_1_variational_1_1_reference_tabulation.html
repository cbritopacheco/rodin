ReferenceTabulation

Owned scalar basis values and reference derivatives.

Scalar basis values and first derivatives at reference samples.

Values are indexed by sample and basis; derivatives additionally carry a reference-coordinate index. This data object owns its storage and has no cache identity, lookup, eviction or finite-element dependency.

Sizes values and first derivatives together.

Parameters

Resizing can invalidate previously borrowed views, including when a later allocation fails. Storage sizes and published extents remain coherent.
