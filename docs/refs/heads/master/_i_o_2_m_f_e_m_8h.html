Enum documentation

enum class Keyword

Keywords used in MFEM mesh file format.

These keywords identify different sections of an MFEM mesh file.

Enumerators
Dimension

Dimension section keyword.
Elements

Elements section keyword.
Boundary

Boundary section keyword.
Vertices

Vertices section keyword.

enum Ordering

Data ordering for grid function storage.

Specifies how vector-valued grid function data is organized in memory.

Enumerators
Nodes

Node-major ordering: XXX..., YYY..., ZZZ... (all x-components, then all y-components, etc.).
VectorDimension

Vector dimension-major ordering: XYZ, XYZ, ... (interleaved components).
