Partial differential equations » Solving the Helmholtz equation

Solve a complex wave problem and check it against a manufactured solution.

This example extends the Poisson workflow to a complex-valued wave amplitude. It introduces a negative mass term, explains why conjugate gradients is unsuitable here, and exports the real and imaginary parts of the computed field separately.

The weak formulation

For complex test functions with zero boundary trace, the weak equation is

The bar denotes complex conjugation. Rodin's complex forms are linear in the trial field and conjugate-linear in the test field. The negative mass term makes this system indefinite, so the positive-definiteness requirement of CG is not satisfied.

1. Resolve the wave on a mesh

The program generates a unit-square triangular mesh with 97 vertices in each coordinate direction: 9409 vertices and 18432 triangles. The wavelength in the horizontal direction is .

  constexpr size_t nodes = 97;
  const Real pi = Math::Constants::pi();
  const Real waveNumber = 4 * pi;
  Mesh mesh = Mesh().UniformGrid(Polytope::Type::Triangle, {nodes, nodes});
  mesh.scale(1.0 / (nodes - 1));
  mesh.getConnectivity().compute(1, 2);

Resolving a wavelength is necessary but does not by itself control wave dispersion or proximity to resonance. Refinement is still needed to assess the error for the frequency of interest.

2. Define the complex problem

P1<Complex> stores a complex coefficient at each mesh vertex. Both the source and the boundary values come from the same manufactured solution.

  P1<Complex> vh(mesh);
  TrialFunction u(vh);
  TestFunction v(vh);
  ComplexFunction exact = [=](const Point& point) {
    return std::exp(Complex(0, waveNumber * point.x())) * std::sin(pi * point.y());
  };
  auto source = pi * pi * exact;

  Problem helmholtz(u, v);
  helmholtz = Integral(Grad(u), Grad(v)) - waveNumber * waveNumber * Integral(u, v) -
    Integral(source, v) + DirichletBC(u, exact);

As in the Poisson example, the load is subtracted to express a residual. Here the additional negative mass term represents the time-harmonic wave term.

3. Solve the indefinite system

Sparse LU is used for this modest two-dimensional demonstration. It does not require a positive definite matrix. The program checks solver success before exporting the result.

  Solver::SparseLU solver(helmholtz);
  solver.solve();
  if (!solver.success())
    return EXIT_FAILURE;

4. Inspect real and imaginary parts

The output stores two real-valued fields, avoiding ambiguity when opening a complex field in a visualization application.

  P1 realSpace(mesh);
  GridFunction realPart(realSpace);
  GridFunction imaginaryPart(realSpace);
  realPart = Re(u.getSolution());
  imaginaryPart = Im(u.getSolution());
  IO::XDMF xdmf("Helmholtz");
  xdmf.grid().setMesh(mesh).add("real", realPart).add("imaginary", imaginaryPart);
  xdmf.write().flush();

Complete program

#include <cmath>
#include <cstdlib>

#include <Rodin/Solver.h>
#include <Rodin/Geometry.h>
#include <Rodin/Assembly.h>
#include <Rodin/Variational.h>
#include <Rodin/IO/XDMF.h>

using namespace Rodin;
using namespace Rodin::Geometry;
using namespace Rodin::Variational;

int main()
{
  constexpr size_t nodes = 97;
  const Real pi = Math::Constants::pi();
  const Real waveNumber = 4 * pi;
  Mesh mesh = Mesh().UniformGrid(Polytope::Type::Triangle, {nodes, nodes});
  mesh.scale(1.0 / (nodes - 1));
  mesh.getConnectivity().compute(1, 2);

  P1<Complex> vh(mesh);
  TrialFunction u(vh);
  TestFunction v(vh);
  ComplexFunction exact = [=](const Point& point) {
    return std::exp(Complex(0, waveNumber * point.x())) * std::sin(pi * point.y());
  };
  auto source = pi * pi * exact;

  Problem helmholtz(u, v);
  helmholtz = Integral(Grad(u), Grad(v)) - waveNumber * waveNumber * Integral(u, v) -
    Integral(source, v) + DirichletBC(u, exact);

  Solver::SparseLU solver(helmholtz);
  solver.solve();
  if (!solver.success())
    return EXIT_FAILURE;

  P1 realSpace(mesh);
  GridFunction realPart(realSpace);
  GridFunction imaginaryPart(realSpace);
  realPart = Re(u.getSolution());
  imaginaryPart = Im(u.getSolution());
  IO::XDMF xdmf("Helmholtz");
  xdmf.grid().setMesh(mesh).add("real", realPart).add("imaginary", imaginaryPart);
  xdmf.write().flush();
  return 0;
}
