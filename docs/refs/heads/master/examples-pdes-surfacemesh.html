Solve reaction–diffusion on a triangulated unit sphere.

A surface mesh has two-dimensional cells whose coordinates lie in three-dimensional space. This example builds a closed spherical surface and solves a scalar reaction–diffusion equation on it. The same variational syntax as in a planar problem uses tangential gradients and surface measure.

1. Build the surface geometry

A tetrahedral cube is centered at the origin. Its boundary is extracted with skin(), then each surface vertex is projected radially onto the unit sphere.

  constexpr size_t nodes = 11;
  Mesh volume = Mesh().UniformGrid(Polytope::Type::Tetrahedron, {nodes, nodes, nodes});
  volume.scale(2.0 / (nodes - 1));
  volume.displace(VectorFunction{-1, -1, -1});
  volume.getConnectivity().compute(2, 3);
  Mesh mesh = volume.skin();
  for (Index vertex = 0; vertex < mesh.getVertexCount(); ++vertex)
  {
    Math::SpatialPoint point = mesh.getVertexCoordinates(vertex);
    point.normalize();
    mesh.setVertexCoordinates(vertex, point);
  }

The result has 602 vertices and 1200 triangular facets. Its topological dimension is two and its embedding dimension is three. The facets are flat: this is a polyhedral approximation to the sphere, not an exact curved sphere. Interior points of a facet generally lie inside the sphere.

2. Define the surface problem

P1 defines a continuous field affine on each facet. Rodin uses the rectangular geometric Jacobian to evaluate the tangential gradient and the area measure, so no manually projected gradient is needed.

  P1 vh(mesh);
  TrialFunction u(vh);
  TestFunction v(vh);
  RealFunction source = [](const Point& point) { return 7 * point.x() * point.y(); };
  Problem reactionDiffusion(u, v);
  reactionDiffusion = Integral(Grad(u), Grad(v)) + Integral(u, v) - Integral(source, v);

The formula is assembled on , with the source evaluated at its integration points. Comparing with therefore includes both finite element error and geometric approximation error. Raising only the field degree would not make a flat geometric mesh exactly spherical.

3. Solve and visualize the field

The stiffness plus reaction matrix is symmetric positive definite, so conjugate gradients is appropriate. The mesh and scalar field are exported together after convergence is checked.

  Solver::CG solver(reactionDiffusion);
  solver.setTolerance(1e-10).solve();
  if (!solver.success())
    return EXIT_FAILURE;
  IO::XDMF xdmf("SurfaceMesh");
  xdmf.grid().setMesh(mesh).add("u", u.getSolution());
  xdmf.write().flush();

Open SurfaceMesh.xdmf in ParaView, color by u, and select Surface With Edges to inspect the geometry. Positive and negative lobes reflect the sign of . No warp filter is required: the mesh is already embedded in 3D.

Complete program

The program generates its mesh and needs no resource file.

#include <cmath>
#include <cstdlib>

#include <Rodin/Solver.h>
#include <Rodin/Geometry.h>
#include <Rodin/Assembly.h>
#include <Rodin/Variational.h>
#include <Rodin/IO/XDMF.h>

using namespace Rodin;
using namespace Rodin::Geometry;
using namespace Rodin::Variational;

int main()
{
  constexpr size_t nodes = 11;
  Mesh volume = Mesh().UniformGrid(Polytope::Type::Tetrahedron, {nodes, nodes, nodes});
  volume.scale(2.0 / (nodes - 1));
  volume.displace(VectorFunction{-1, -1, -1});
  volume.getConnectivity().compute(2, 3);
  Mesh mesh = volume.skin();
  for (Index vertex = 0; vertex < mesh.getVertexCount(); ++vertex)
  {
    Math::SpatialPoint point = mesh.getVertexCoordinates(vertex);
    point.normalize();
    mesh.setVertexCoordinates(vertex, point);
  }

  P1 vh(mesh);
  TrialFunction u(vh);
  TestFunction v(vh);
  RealFunction source = [](const Point& point) { return 7 * point.x() * point.y(); };
  Problem reactionDiffusion(u, v);
  reactionDiffusion = Integral(Grad(u), Grad(v)) + Integral(u, v) - Integral(source, v);

  Solver::CG solver(reactionDiffusion);
  solver.setTolerance(1e-10).solve();
  if (!solver.success())
    return EXIT_FAILURE;
  IO::XDMF xdmf("SurfaceMesh");
  xdmf.grid().setMesh(mesh).add("u", u.getSolution());
  xdmf.write().flush();
  return 0;
}
