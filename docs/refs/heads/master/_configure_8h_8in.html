Rodin/Configure.h.in file

Build configuration and feature-selection macros for Rodin.

Contents

  • Representative use
  • Module-specific controls
  • Reference
    • Defines

CMake generates Rodin/Configure.h from this template. Include the generated header to inspect the library version and enabled backends; optional feature macros are defined only when their feature is enabled.

See also

Configuration guide

Representative use

#include <Rodin/Configure.h>
#if defined(RODIN_USE_MPI)
// Code requiring the MPI backend.
#endif

Module-specific controls

Controls declared by individual modules remain documented on their own header pages: RODIN_GEOMETRY_REQUIRE_INCIDENCE for mesh connectivity, RODIN_QF_GRUNDMANNMOLLER_MAX_ORDER for quadrature capacity, and RODIN_VARIATIONAL_H1ELEMENT_MAX_VECTOR_DIMENSION for H1 vector capacity.

#define RODIN_SILENCE_EXCEPTIONS

Indicates if Rodin exceptions are silenced.

If defined, this directive will prevent Rodin from outputting the error messages. It does not prevent the exception from being thrown.

#define RODIN_FUZZY_CONSTANT

Legacy default tolerance intended for fuzzy scalar comparisons.

Absolute threshold in the compared values' units; the value is a numerical policy, not a scale-independent error bound. Currently unused in Rodin's implementation; retained as a configuration macro for downstream users.
