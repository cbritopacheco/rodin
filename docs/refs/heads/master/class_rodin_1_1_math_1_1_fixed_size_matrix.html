Fixed-size matrix type.

A compile-time fixed-size matrix. Both dimensions are known at compile time, enabling optimizations and stack allocation without additional storage. Dot products conjugate the right operand.

Example uses:

  • 2×2 rotation matrices
  • 3×3 transformation matrices
  • Small dense blocks in larger systems
