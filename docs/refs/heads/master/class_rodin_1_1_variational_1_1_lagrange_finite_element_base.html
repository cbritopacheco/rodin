Optional<size_t> getLagrangeDegree(size_t order, std::initializer_list<size_t> directions) const

Bounds a native Lagrange reference space in selected directions. The returned bound describes the space with the supplied family index; it does not necessarily describe this object's own family index.

Parameters
order Family index of the Lagrange space.
directions Reference-coordinate indices.
Returns A directional bound, or no bound for invalid directions, unsupported selections, or an unrepresentable degree.
