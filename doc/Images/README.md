# Documentation artwork

The footer uses the upstream Doxygen wordmark from
[Doxygen 1.14.0](https://github.com/doxygen/doxygen/blob/Release_1_14_0/doc/doxygen_logo.svg).
A CSS mask renders the logo in the surrounding text colour, adapting to light
and dark themes. The m.css credit uses a bold text link.

Doxygen is distributed under its
[upstream licence](https://github.com/doxygen/doxygen/blob/Release_1_14_0/LICENSE).

`Boost.svg` is the unmodified transparent Boost logo from the
[Boost website documentation](https://github.com/boostorg/website-v2-docs/blob/develop/antora-ui/src/img/boost-logo-transparent.svg).
It identifies the Boost Software License block on the home page. Its use is
covered by the [Boost logo policy](https://docs.cppalliance.org/contributor-guide/docs/logo-policy-media-guide.html).
The badge preserves the logo's colour, proportions and silhouette.
