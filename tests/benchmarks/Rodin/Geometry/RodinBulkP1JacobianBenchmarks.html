Bulk P1 geometry contractions and their mapped-quadrature consumer.

Measured operation

Isolates the bulk geometry operation used by public assembly.

Architecture

The actual native P1 element and its existing reference table are used. Bulk contractions overwrite retained output matrices; OwnedQuadrature constructs/replaces the mapped points used by variational integrators. PreparedPoint constructs and destroys stack points from untimed prepared Jacobians. RetainedPoints clears and refills a reserved point vector from the same inputs, without timed vector allocation or Jacobian evaluation. These scopes expose public source operations, not additive exclusive-time fractions: their storage lifetimes and cache traffic differ. No scope includes mesh construction, reference-table initialization, analytic guards, operator assembly or solving. Full assembly is measured separately by its owning Assembly targets on matched quadrature orders.

Affine controls represent \(x=b+A\widehat x\), with nonzero mixed components, so the independent Jacobian is \(A\). Perturbed controls exercise the same native basis without assuming an affine Jacobian on tensor-product, wedge or rational pyramid cells. Simplex P1 maps remain affine. Every result must exactly reproduce the original pointwise contraction and its dimensions; affine cases additionally satisfy an independent analytic roundoff budget. Wrong entries or dimensions must be rejected. No new cache or alternative production geometry path is added.

Recorded results

Each case retains its original inputs, iteration policy and correctness checks. Raw reports preserve counters, repetitions and the Google Benchmark context. CPU, wall and manually supplied times are labeled separately; unlike operations and configurations are not averaged together.
