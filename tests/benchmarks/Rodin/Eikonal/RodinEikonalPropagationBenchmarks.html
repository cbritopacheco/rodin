Compares tensor FMM and serial/OpenMP native-cell FIM on matched affine triangle and tetrahedron meshes. A rotation and stretch map the reference grid to a mesh nonobtuse in the constant inverse-velocity metric. Both methods use the same zero-time corner source and squared-velocity tensor.

Wall-clock timing includes seeding, cellwise coefficient preparation, and propagation. Mesh construction, coefficient-expression construction, reference solves, and error checks are excluded. Counters report vertices, cells, dimension, velocity ratio, workers, FIM rounds, coefficient evaluations per solve, maximum analytic error, and maximum difference from tensor FMM. FIM workers must reproduce the serial field and round count exactly.

FMM uses analytic simplex updates while FIM uses numerical native-face search with cellwise coefficients. Their difference includes this local-update approximation. Search resolution and coefficient evaluation counts are reported. FIM must sample each cell exactly once per solve; there is no path quadrature. Measurements characterize these constant-coefficient affine cases, not arbitrary native cells or anisotropy.
