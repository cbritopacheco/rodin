# Poisson h-convergence

The tests solve

\[
  -\Delta u=f \quad\hbox{in }\Omega=(0,1)^d, \qquad
  u=g \quad\hbox{on }\partial\Omega
\]

with conforming elements of degree `K=1,2,3`. The Galerkin approximation is
expected to satisfy

\[
  \lVert u-u_h\rVert_{H^1}=O(h^K), \qquad
  \lVert u-u_h\rVert_{L^2}=O(h^{K+1})
\]

for the smooth manufactured solutions below. Errors are integrated directly at
high quadrature order; this avoids making the convergence oracle depend on an
interpolated error field.

The Dirichlet suite contains five complementary validations:

1. **Affine patch test:** `u=1+sum(x_i)` and `f=0`. Since affine functions are
   in `P1`, the discrete solution must be exact up to roundoff on every mesh.
2. **Homogeneous Dirichlet solution:** `u=product(sin(pi*x_i))` and
   `f=d*pi^2*u`. This verifies the optimal `L2` and `H1` rates with zero boundary
   data.
3. **Nonhomogeneous Dirichlet solution:** `u=exp(sum(x_i))` and `f=-d*u`.
   This checks the same rates while exercising nonzero essential data.
4. **Quadratic h-convergence:** the homogeneous sine-product solution in
   `H1<2>` must converge with third-order `L2` error and second-order `H1`
   error.
5. **Cubic h-convergence:** the same solution in `H1<3>` must converge with
   fourth-order `L2` error and third-order `H1` error.

`BoundaryConditions.cpp` uses the smooth manufactured field

\[
  u=\exp\left(\sum_i x_i\right), \qquad f=-d u,
\]

and partitions the unit-box boundary into the face `x_0=0` and its complement.
It validates three weak boundary formulations for P1, P2, and P3:

1. **Dirichlet--Neumann:** `u` is imposed on `x_0=0`, while
   `grad(u) dot n` is applied naturally on the remaining boundary.
2. **Dirichlet--Robin:** the complementary boundary satisfies
   `grad(u) dot n + alpha*u = r`, with `alpha=2` and manufactured datum
   `r=grad(u) dot n + alpha*u`.
3. **Pure Neumann:** the exact solution is shifted by its domain mean,
   `(e-1)^d`, and a global `P0g` Lagrange multiplier imposes
   `integral(u)=0`. This removes the constant nullspace without changing the
   differential equation.

The natural data are evaluated using `BoundaryNormal` in dimensions two and
three, so the tests cover normal orientation and facet transformations in
addition to boundary quadrature. On the one-dimensional segment, the exact
outward endpoint signs are used because its boundary facets are points.

All seven positive-dimensional geometries generated by `UniformGrid` are
covered: segment, triangle, quadrilateral, tetrahedron, pyramid, hexahedron,
and wedge. The zero-dimensional point geometry is excluded because neither a
Laplacian nor h-refinement defines a Poisson convergence problem there.

The P1 rate tests use 5, 9, and 17 points per coordinate direction. In
particular, the three-dimensional P1 tests intentionally do not start at 3
points: with homogeneous data that grid has only one interior lattice vertex,
so the first comparison measures the onset of resolution rather than an
asymptotic finite-element rate. The higher-order tests use 3, 5, and 9 points;
their additional element-interior degrees of freedom already resolve the
manufactured field on the coarsest mesh.
