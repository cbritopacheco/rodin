# Poisson h-convergence

The tests solve

\[
  -\Delta u=f \quad\hbox{in }\Omega=(0,1)^d, \qquad
  u=g \quad\hbox{on }\partial\Omega
\]

with conforming `P1` elements. The Galerkin approximation is expected to satisfy

\[
  \lVert u-u_h\rVert_{H^1}=O(h), \qquad
  \lVert u-u_h\rVert_{L^2}=O(h^2)
\]

for the smooth manufactured solutions below. Errors are integrated directly at
high quadrature order; this avoids making the convergence oracle depend on an
interpolated error field.

The suite contains three complementary validations:

1. **Affine patch test:** `u=1+sum(x_i)` and `f=0`. Since affine functions are
   in `P1`, the discrete solution must be exact up to roundoff on every mesh.
2. **Homogeneous Dirichlet solution:** `u=product(sin(pi*x_i))` and
   `f=d*pi^2*u`. This verifies the optimal `L2` and `H1` rates with zero boundary
   data.
3. **Nonhomogeneous Dirichlet solution:** `u=exp(sum(x_i))` and `f=-d*u`.
   This checks the same rates while exercising nonzero essential data.

All seven positive-dimensional geometries generated by `UniformGrid` are
covered: segment, triangle, quadrilateral, tetrahedron, pyramid, hexahedron,
and wedge. The zero-dimensional point geometry is excluded because neither a
Laplacian nor h-refinement defines a Poisson convergence problem there.

The common sequence uses 5, 9, and 17 points per coordinate direction. In
particular, the three-dimensional tests intentionally do not start at 3 points:
with homogeneous data that grid has only one interior lattice vertex, so the
first comparison measures the onset of resolution rather than an asymptotic
finite-element rate.
